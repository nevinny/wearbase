Музыка для Reels-слайдшоу.

Источник: Mixkit (mixkit.co/free-stock-music), Mixkit Free License:
коммерческое использование разрешено, атрибуция не требуется, регистрация не нужна.
https://mixkit.co/license/

Файлы обрезаны до 40с, нормализованы к -16 LUFS, AAC 128k — оригиналы длиннее и тяжелее,
а клипы всё равно 15с и дорожка зацикливается.

Заменить трек = положить сюда свой .m4a/.mp3; выбор идёт по имени файла (сортировка),
трек на пост выбирается детерминированно по id поста.
