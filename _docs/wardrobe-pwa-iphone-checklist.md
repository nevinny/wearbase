# Ручная приёмка PWA на iPhone

Проверять после production deploy в актуальном Safari, начиная без активной сессии.

1. Открыть `https://wearbase.ru/ru/wardrobe` и убедиться, что видна кнопка «Установить на iPhone».
2. Нажать «Поделиться» → «На экран Домой» → «Добавить».
3. Закрыть Safari и запустить WEARBASE с новой иконки: приложение открывается отдельным окном.
4. Anonymous launch показывает вход, не перебрасывая пользователя во внешнее окно Safari.
5. Войти тестовым аккаунтом: после входа открывается `/account/wardrobe-app`.
6. В авиарежиме повторно открыть приложение: показывается экран «Нет подключения» без состава
   семьи, вещей, API-ответов и пользовательских фото.
7. Вернуть сеть и нажать «Повторить»: открывается актуальный гардероб.

Зафиксировать модель iPhone, версию iOS/Safari, дату, результат шагов и screenshot standalone-окна.
Ошибка любого шага блокирует отметку iPhone install path как production-ready.
