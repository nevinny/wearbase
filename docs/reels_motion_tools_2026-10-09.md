# HyperFrames и Remotion для конвейера рилсов (оценка 2026-10-09)

Вывод: это НЕ «тот же класс», что наш `render-template.cjs`, и не одно и то же между собой. Оба дают то, чего у нас нет: анимацию по таймлайну (пружины, стаггер слов, караоке по таймстампам слов). ## Сравнение с render-template.cjs

| | render-template.cjs | HyperFrames | Remotion |
|---|---|---|---|
| Модель | canvas + ffmpeg, сцена в JSON-шаблонах | HTML + GSAP (таймлайн на паузе), data-атрибуты | React-компонент от номера кадра |
| Кинетика/пружины | нет (только зум) | да (GSAP: back, stagger) | да (spring, interpolate) |
| Караоке под слова TTS | нет | вручную в GSAP; есть whisper-интеграция в init | `@remotion/captions`, данные слов -> компонент |
| Переходы между клипами | нет | да | `@remotion/transitions` |
| Аудио/микс | отдельный ffmpeg-шаг | встроенные атрибуты (volume, fade) | свои компоненты |
| Порог входа | JSON-шаблон | HTML + GSAP, GSAP тянется с CDN | React + TS, тяжёлый тулчейн |
| Проверки | warnings по кеглю/безопасной зоне | `check`: lint, контраст, layout | нет встроенных |
| Лицензия | своя | Apache-2.0 | условная (см. выше) |

## Как встроить

1. Не заменять `render-template.cjs`: безголосые шаблоны он делает быстро, детерминированно, с fingerprint-кешем и проверкой безопасной зоны — всё это пришлось бы переписывать.
2. Озвученные рилсы (qwen-tts) — единственный случай, где нужны слова с таймстампами. Рендерить слой «плашка + караоке» отдельным клипом (Remotion: данные слов на входе), мерджить ffmpeg-ом с фото-слоем и аудио. После mux прогонять `qa-transcript.cjs`.
3. Перед внедрением: перенести проверку безопасной зоны (300–1500 px) и кегль >=76 в обёртку; зашить GSAP локально (CDN у HyperFrames — зависимость от сети).

## Рекомендация

Remotion: быстрее на тёплом старте, сильная экосистема (captions, transitions), условия лицензии нам подходят — пилот для озвученных рилсов. HyperFrames: лёгкая установка и встроенный `check`, но медленнее на коротком клипе и держится на GSAP с CDN; возвращаться, если захотим motion-графику из HTML-блоков каталога. Оба смоука — один клип, поэтому «лучше/хуже» не доказано; решение о пилоте — после прогона реального озвученного ролика.
