  из своих вещей»/«...собирает образы из твоего гардероба» (69/мес, но точное
  словесное совпадение с фичей). Пишется editorially (НЕ через `app:seo:listicle`/
  `SeoGuideCommand` — конвейер CTA-ит на покупки в каталоге, здесь интент
  противоположный — «используй своё»). Та же ветка.

## Фаза 1 — после публикации Фазы 0, гейт: сигнал по воронке `WardrobeActivationEvent`
(органика → первая вещь → первый образ) хотя бы за 2-3 недели

- **Статья №2** — «Оцифровка гардероба: с чего начать» (или близкая формулировка).

  (предупреждение Codex).
- **Статья №3** — топ-N листикл приложений для гардероба. Обоснование: живая

  Oskelly, Т—Ж), не соло-лендингами. Кандидаты в список (см. полный разбор в чате

## Сознательно НЕ берём в контент

- **«Семейный гардероб» / «гардероб для семьи»** — омоним реальной розничной сети
  магазинов одежды (адреса/график работы/фото витрин в выдаче), к фиче отношения
  не имеет. Использовать эту фразу в контенте фичи — только путать интент.
- **«Цифровой гардероб» отдельной страницей** — держать только как синоним внутри
  текста лендинга/статей, не отдельный таргет/URL.
- Семейный угол фичи (передача вещей между детьми и т.п.) продуктово реален
  (`docs/family_purchase_learning.md`, `docs/wardrobe_roadmap.md`), но спрос под
  него по факту не найден («семейный гардероб» — мёртвая ветка) — если продвигать
  этот угол контентом, нужен отдельный keyword-заход с другими формулировками
  («гардероб ребёнка», «детская одежда учёт приложение» и т.п.), не сделанный пока.

для всех статей этого плана (обоснование выше, п. Фаза 0/1).
