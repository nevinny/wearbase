# Площадки для публикации SEO Boost / GEO-листиклов

Полный список внешних площадок для размещения статей-рейтингов (`app:seo:listicle`).
Основа — КП ContentMagic (`~/Downloads/KP_SEO_Boost.md`, 20 площадок) + Яндекс.Дзен.

**Эффект:**
- **SEO** — даёт ссылку с весом (dofollow/полезный nofollow) → усиливает позиции wearbase.ru.
- **GEO** — AI (ChatGPT/Perplexity/Gemini/YandexGPT) парсит и цитирует в ответах.

**Автоматизация:**
- 🟢 **API/прямая** — есть API или простая форма (можно автопостить).
- 🟡 **браузер** — нет API, но размещается скриптом (Claude-in-Chrome / Playwright).
- 🔴 **ручками** — нужна модерация/антибот/ручной аккаунт; только вручную или полу-ручной плейбук.

> ⚠️ Статьи НЕ публикуем на wearbase.ru (self-домен, исключён `UrlFilter`). Только внешние площадки; ссылки в ItemList ведут на карточки брендов каталога (бэклинки).

## Приоритет запуска (от простого к сложному)

1. **🟢 Сначала автоматизируемые** (быстрый старт, есть API/форма):
   `telegra.ph` · `blogspot.com` · `livejournal.com` · `pastelink.net`.
2. **🟡 Затем браузерные** (Claude-in-Chrome / Playwright, по одному аккаунту):
   `cont.ws` · `boosty.to` · `salda.ws` · `press-release.ru` · `pabliko.ru` · `subscribe.ru` · `mt.ru` · `ok.ru` · Q&A.
3. **🔴 В последнюю очередь — ручной плейбук** (строгая модерация/антибот, максимальный эффект):
   `vc.ru` · `dtf.ru` · `spark.ru` · `dzen.ru` · `pikabu.ru` · `sostav.ru` · `otvet.mail.ru`.

## Тон под площадку (опция `--platform` листикла)

Реализованные тоны: `vc` (экспертный обзор) · `dtf` (личный тест) · `pikabu` (личный опыт/UGC) · `press` (пресс-релиз) · `blog` (личный блог) · `dzen` (статья для Дзена). Остальные площадки переиспользуют ближайший тон (telegra.ph/livejournal → `blog`, sostav.ru → `vc`, и т.д.).

## Правовое (важно)

Маркировать рекламу там, где это реклама (ФЗ о рекламе РФ, ОРД/токен). Рейтинги — на реальных фактах (grounded), не «мы №1 всегда». См. [seo_boost.md](seo_boost.md), [marketing_seo.md](marketing_seo.md).
