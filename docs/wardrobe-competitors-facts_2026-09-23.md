## Fits (fits-app.com)

Источники: `/knowledge/free-vs-paid-features`, `/digital-wardrobe`.

- **Free**: безлимит вещей и образов, безлимит удаления фона, AI-определение
  категории/цвета/сезона, до 5 пользовательских тегов, безлимит коллекций,
  планировщик образов.
- **Pro (платно)**: безлимитный AI-стилист (чат + предложения образов), безлимит
  тегов (vs 5 на free), доп. ракурсы вещи (напр. вид сзади), 30 AI-кредитов/мес
  (улучшение фото + виртуальная примерка), расширенная статистика, причёски/стикеры.
- Доп: 1M+ пользователей, рейтинг 4.7/5 (App Store, со слов лендинга), два режима
  сборки образа — коллаж и «примерочная» с манекеном, есть соц-функции (гардеробы
  друзей), помощь при сборе чемодана.
- ⚠️ **Прежний вывод «платный вход отталкивает» (по частым запросам «взлом»/
  «скачать») неверен** — Codex уже это ловил раньше в этой же цепочке, теперь
  подтверждено первоисточником: щедрый free, платно — только продвинутый AI.

## GetWardrobe (getwardrobe.com)

- **Free**: до 100 вещей на аккаунт (across all platforms), AI-генератор образов
  (базовый режим — 10 комбинаций за раз), планирование с прогнозом погоды +
  календарь, автоудаление фона при загрузке, AI определяет категорию/доминирующие
  цвета и предлагает название вещи.
- **Premium (платно)**: $49.99/год ($4.17/мес) — безлимит вещей, **семейные
  гардеробы** (прямой аналог нашей family-фичи!), списки для сборов в поездку,
  учёт стоимости износа вещи, расширенные фильтры. Пробный период без карты.
- Платформы: iOS, Android, macOS, веб (app.getwardrobe.com), синк между устройствами.

## N2B (n2b-style.com)

- Позиционируется шире, чем личный гардероб: конструктор образов для частных
  пользователей + профессиональных стилистов (удалённая работа с клиентами) +
  брендов/фэшн-школ (визуализация, контент).
- **Free**: 5-дневный триал, до 10 вещей, базовые уроки/вдохновение — сильно
  урезанная пробная версия, не полноценный бесплатный тариф.
- **Платно**: полный функционал, подписка 1/3/12 месяцев картой.
- Есть «банк стилистов», капсульные подборки, лукбук по сезонам/поводам.
- Платформы: iOS, Android.

## Outfitly (outfitlyapp.com) — данных нет

Страница на JS без серверного рендера — WebFetch вытащил только тег `<title>`
(«AI-гардероб, планировщик образов и виртуальная примерка»). Функциональность,
цены, лимиты — не подтверждены. **Не писать конкретику про Outfitly в статье**,
только нейтральное упоминание по названию/позиционированию.

## Acloset — не подтверждено напрямую

Домен `acloset.co` не резолвится (`ENOTFOUND`) — правильный домен не найден с
первой попытки. Всё, что есть — пересказ из статьи Т—Ж (см. keyword-документ):
«полностью бесплатное», iOS+Android, автоподбор по погоде, учёт частоты носки.
Это вторичный источник (не первоисточник) — в статье помечать как «по данным
обзора Т—Ж», не как проверенный факт.

## Tidy — данных нет вообще

Только цифры спроса из Wordstat (102+20/мес), содержательных фактов о продукте
не нашлось (домен/лендинг не идентифицирован в рамках этого захода).

## Что это меняет для статьи №2 контент-плана

- Убрать/переписать любое утверждение вида «конкурент X отталкивает платным
  входом» — конкретно для Fits это прямо опровергнуто первоисточником.
- Добавить реальные цифры Fits/GetWardrobe/N2B (см. таблицы выше) вместо общих
  фраз «есть возможность..., судя по описанию на сайте...».
- GetWardrobe's «семейные гардеробы» в Premium — прямая точка сравнения с нашей
  бесплатной family-фичей, стоит явно проговорить (честно, без принижения
  конкурента — просто факт «у нас это бесплатно»).
- Outfitly и Tidy — оставить нейтральными/короткими упоминаниями без конкретики.
- Acloset — с пометкой источника (Т—Ж), не как собственноручно проверенное.
