## Кластеры трения

### 1. Edit-ошибки агента (самый частый шум)
«File has not been read yet» / «String to replace not found» / «File has been modified since read».
~50+ случаев во всех батчах: 22 (сессия 26–28.06), ~10 (21–23.06), 7 (18–19.06), 6–7 (16–19.06),
5 (30.06–03.07), и т.д. Отдельный подвид — гонки параллельных TG-сессий, правящих одни файлы
(03.07, closed-loop: две копии сессии наперегонки).
**Лечение:** привычка агента (Read перед Edit, при «modified since read» — перечитать и примирить);
память `parallel-session-race` уже написана. Файлами не правится.

### 2. Env-слепота Mac
- Поиск пути php с перебором ~7 вариантов (03.07 — дважды; 21.06 — 5 проб; 22.06 — 2).
  Верные пути: `/opt/homebrew/bin/php`, запасной `/opt/homebrew/opt/php@8.2/bin/php`.
- `cache:clear` трижды падал на дефолтных 128M (01.07: 16:57, 19:46, 19:47) до `-d memory_limit=512M`.
- youtube-dl not found → `/opt/homebrew/bin/yt-dlp` (03.07); trafilatura glob mimo (23.06).
- `.env.local` на проде: syntax error line 15 → каскад «Access denied» PDO (02.07, ~5 ошибок).

### 3. SSH / IP-зоопарк серверов
- IP LLM-сервера переоткрывается каждую сессию: .109 → .111 → .119 → 192.168.2.43 → 2.115
  (80 упоминаний «192.168» в одной только сессии 16–19.06; stale DATABASE_HOST).
- Обрывы ssh exit 255: 8 раз 03.07 (`ssh llm`, `ssh regru`), 2+ 23.06; Host key verification failed
  после смены железа (25.06, юзер: «поправь ssh-алиас на .111 и обнови память»).
- Диск .119 забит 100% (22.06, юзер предупреждал заранее 4+ раза, ~21 упоминание);
  нехватка RAM под модели («requires 20.9 GiB, available 9.1»).
- Объём: 99 вызовов `ssh regru` + 54 `ssh llm` за одну сессию 01–03.07.

### Правки CLAUDE.md
1. **Блок «Окружение Mac»**: `PHP=/opt/homebrew/bin/php` (запасной `php@8.2`); всегда
   `-d memory_limit=512M` для cache:clear и батчей; `yt-dlp=/opt/homebrew/bin/yt-dlp`;
   trafilatura — путь из venv (см. память); ⚠️ `dbal:run-sql`: только однострочный SELECT,
   «0 rows affected» на SELECT = артефакт раннера, НЕ пустая таблица.
2. **Карта хостов**: `ssh llm` = LLM-сервер/риг (сейчас 192.168.0.111; IP непостоянен → скан
   подсети на порт 11434); `ssh regru` = прод; лимиты .119 (диск/RAM); при Host-key-fail —
   `ssh-keygen -R`.
3. **Правило инициативы**: очевидный следующий шаг делать сразу, без «Хочешь…?»; спрашивать
   только перед необратимым/дорогим/внешне-видимым. (Корректирует Karpathy-блок «Think Before
   Coding», который сейчас толкает к переспрашиванию.)
4. **Правило фиксации знаний**: каждый research-вывод (пример: reranker) — сразу в `docs/` или
   память, в ответе давать ссылку на файл; иначе вопрос возвращается.
5. **Авто-коммит**: атомарный коммит после каждой законченной правки, не дожидаясь «закоммить»
   (пуш — по-прежнему по запросу).
