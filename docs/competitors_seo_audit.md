### Сквозные дыры у ВСЕХ — открытые двери WEARBASE
1. **Контента на карточках брендов нет нигде** — везде «имя + 1-2 строки». RAG-энциклопедия =
   единственный источник глубины → лонгтейл + LLM-видимость.
2. **Structured data только у vitrine** (и то товарная). У WEARBASE уже
   Brand/Product/FAQPage/Breadcrumb/ItemList.
3. **hreflang/мультиязычность — ни у кого.** Все ru-only.
4. **SSR-надёжность:** vitrine и Kiru-app — SPA/Tilda; Twig-SSR краулится стабильнее.

## 2. Куда забирать трафик по одежде (по интенту, кого бьём на каждом слое)

**A. Брендовые — горячий intent, быстрый выигрыш, конвертит → ПРИОРИТЕТ №1**
`[бренд] официальный сайт / купить / интернет-магазин`
- 129+ брендов без своего сайта → в органике конкурента нет; RAG-карточка = топ за 2-4 недели.
- Бьём всех контентом: у vitrine/russian-brand карточка = голое имя.

**B. Категория + гео — средний срок, объём**
`российские бренды женской одежды`, `бренды одежды [город]`, `купить платье у производителя`
- Реальный соперник — **russian-brand.ru** (SSR + `/gorod`(130) + `/kategorii`). Похожи
  структурно → выигрываем контентом: RAG-факты + FAQPage + перелинковка карточка↔гео-хаб↔категория.
- Забрать у vitrine их **стилевые вселенные** как хабы `/style/{streetwear|gorpcore|y2k|opium|archive}`.

**C. Транзакционный товар — где vitrine силён**
`купить {категория} от {бренд} — {цена}₽`
- vitrine держит шаблон + Product/Offer JSON-LD. Догнать: те же транзакционные title + Product
  schema на карточках товара (частично есть, докрутить).

**D. Enemy/инфо-кластер — никто не занял → канал LLM-видимости**
`альтернатива Wildberries`, `где покупать если ушёл с WB`, `российские дизайнеры список`
- Ноль конкурентов с реальным контентом. ChatGPT/Perplexity «посоветуй где купить» + ссылочное
  + верх воронки движения.

## 3. Честные оговорки (иначе план повиснет)

1. **Мультиязычный moat сейчас ВЫКЛЮЧЕН.** Непереведённые локали = ru-fallback под `noindex`
   (`international.md`). «Международный трафик» — латентное преимущество, активируется только с
   реальными переводами. Не продавать как живое.
2. **Индексация капнута ~5.3%** (`marketing_seo.md`). Пока краулится 5%, объём контента не
   сыграет. Чинить индексацию/crawl budget раньше масштаба контента.
3. **Реальная SEO-угроза — vitrine, не бесплатные каталоги.** У vitrine транзакц. schema +
   стилевые хабы + `/releases`. Бесплатные каталоги слабы в SEO, но бесплатны — они отнимают
   **бренды (acquisition)**, а не поисковый трафик.

## 4. Приоритетная последовательность (отдача/усилие)

1. **Починить индексацию** (снять потолок 5.3%) — фундамент, без него остальное мёртвое.
2. **Брендовые карточки с RAG-контентом** (слой A) — горячий intent, конкурента нет, конвертит.
3. **Product/Offer JSON-LD + транзакционные title** на товарах (слой C) — догнать vitrine.
4. **Гео- и стилевые хабы** `/gorod`, `/style/{slug}` + перелинковка (слой B).
5. **Enemy/инфо-кластер + LLM-видимость** (слой D) — верх воронки, ссылки, движение.
6. **Перевод ru-контента → активировать hreflang** — когда 1-4 дают ru-трафик; разблокирует
   единственный структурный moat, которого нет ни у кого.

**Итог:** неоспоримый рычаг — **глубина контента (RAG) + structured data + SSR + латентный
hreflang**. Бить брендовым и транзакционным intent (конверсия), питать движением и
enemy-кластером (LLM-видимость и ссылки). Но сначала — индексация.
