# Цифровой гардероб: аудитории, боли и рилсы

2026-10-06. Исследование под рилсы гардероба после того, как v1 («Что надеть утром», иконки) и v2
(`docs/wardrobe_reels_scenarios.md`: «Куртка на вырост» и др.) забракованы: не про реальные сценарии.
Принцип владельца: **идём от боли, которая есть, предлагаем решение; нет решения — строим его.**

Источники: три параллельных разбора — код + прод-использование (SELECT на regru), рынок (Wordstat
06.10, отзывы конкурентов, TikTok/Reels), наши соцданные (social_post_metric, docs).

## 0. Честная точка отсчёта

- **Внешних пользователей с вещами — 0.** Все 56 вещей на проде — наша семья (44 у жены, 39 из них —
  ссылки WB с ценами; 10 у старшей дочери; 2 у владельца). Внешние: 3 регистрации, все с пустым шкафом;
  один упёрся в «добавьте хотя бы две вещи» у стилиста и ушёл.
- **IG-аудитории под гардероб нет.** 45 brand-рилсов: ~71 просмотр в среднем, 0 сохранений; статику видят
  только подписчики (reach 146 на 52 поста). Рилсы — холодная раздача → сегмент выбирает **хук**, а не база.
- **Лендинг /ru/wardrobe**: ~70 заходов за 11 дней → 1 регистрация. Метрика правды для рилсов —
  `wardrobe_activation_event` на проде + UTM на ссылке профиля (сейчас атрибуции из IG нет).

## 1. Сегменты (от владельца — каркас) × доказательства

Сегменты сформулированы владельцем по опыту использования (06.10). Наложены: спрос (Wordstat 06.10),
статус функций в коде/на проде, боли из отзывов конкурентов. JTBD частично из DeepSeek-черновика
(`~/Downloads/deepseek_text_20261006_04d208.txt`) — **без источников, только гипотезы**; его цифры
(«26% женщин», «72% хотят персонализацию») не использовать.

Статусы функций: ✅ работает · 🟡 частично · 🔨 нет (строим; рилс — после выпуска).

### С1. Одинокая женщина 25–40 — «образ на работу каждый день»
- **Боль:** «полный шкаф — нечего надеть», утро 15–20 мин на выбор, страх выглядеть неуместно.
- **Момент:** вечер перед рабочим днём / утро; новая работа; важная встреча.
- **Спрос:** «что сегодня надеть» 8k (по погоде 1.6k), «приложение для гардероба» 2.1k — самый массовый вход.
- **Решение:** образы из своих вещей ✅ ночные образы по поводам (работа/встреча/…) — 🟡 стилист на проде
  падает, генерация только с Mac, погода выключена; план образов на неделю 🔨; cost per wear ✅.
- **Риск:** оцифровка шкафа — главная причина оттока в нише → онбординг «пачкой» 🟡.

### С2. Женщина-супруга — образы для себя и мужа
- **Боль:** гардероб мужа — «чёрный ящик», муж не любит шопинг, собрать обоих на выход/в отпуск.
- **Момент:** совместный выход, свадьба/корпоратив, отпуск.
- **Решение:** профиль мужа в семье ✅ (семья: инвайт второго взрослого); образ мужу из его вещей ✅
  (стилист по участнику — 🟡 тот же сбой стилиста); **парные образы** 🔨; сборы на двоих 🔨.
- **Спрос:** прямого нет — сегмент берём хуком («собираю мужа на корпоратив»).

### С3. Мать 1–2 детей — ведёт гардероб себя и всей семьи
- **Боль:** «какой у него сейчас размер», что уже куплено, сборы в сад/школу, ребёнок просит купить с WB.
- **Наблюдение владельца:** функции переиспользования детских вещей у этого сегмента используются **мало** —
  в рилсах для С3 не продавать «передачу», продавать размер/учёт/покупки.
- **Спрос:** «размер одежды ребёнка» и хвосты ≈21.4k — **крупнейший** из найденных; «на вырост» — 10.
- **Решение:** детские профили без email ✅; запрос ребёнка «купи» → решение родителя ✅ (🐞 напоминания
  без капа); размер ребёнка ↔ размер вещи, «что стало мало» 🔨; сборы в сад/школу (чек-лист) 🔨.

### С4. Многодетная мать — передача, финансы, матрица
- **Наблюдение владельца:** этот сегмент **активно** пользуется передачей вещей между детьми, финансами
  гардероба и матрицей.
- **Боль:** огромный объём вещей, ограниченный бюджет, дети разных возрастов; сейчас — Excel и пакеты с
  подписанными размерами.
- **Решение:** передача старший → младший с историей ✅; статистика трат по участникам ✅; матрица семьи и
  потребности к сезону ✅; массовая передача пачкой 🔨; «выросшее → Авито» 🔨; бюджет сезона 🔨.
- **Конкуренты:** детский слой не продаёт никто → самая свободная ниша; Авито: детская одежда +28–32% г/г.

### С5. Женщина, выходящая из материнства — «время на себя»
- **Боль:** «не знаю, что мне идёт», гардероб устарел, хочется выглядеть стильно на выходах.
- **Момент:** театр, ресторан, кино, выход на работу, путешествие.
- **Решение:** образы по поводу ✅ (поводы есть в ночной генерации, 🟡 надёжность); **сборы в поездку**:
  что взять, чек-лист, образы по дням 🔨; капсула 🔨 (спрос «капсульный гардероб» 4.5k, «для женщины 50» 83).
- **Канал:** часть 40+ сидит в VK/TG сильнее, чем в IG (открытый вопрос).

### С6. Личный ассистент богатой семьи — сотни вещей на каждого
- **Боль:** масштаб, статусы (стирка, химчистка, ремонт), закупки из-за границы и отслеживание, отчёт
  работодателю, доступ с разных устройств.
- **Решение:** статус «чистая / в стирке» ✅; журнал жизненного цикла вещи (химчистка, ремонт молнии/подошвы/
  подгиб) ✅ в коде (`WardrobeItemLifecycleEvent`); лендинг консьержа есть; роли ассистента/доступ 🔨;
  отслеживание закупок 🔨; отчёт 🔨. Подробно про рынок — `docs/wardrobe_hnwi_services.md`.
- **Канал:** не масс-Reels; B2B/рекомендации, рилс «за кадром гардеробной» — как имиджевый.

## 3. Рилсы: углы по сегментам

Правила из `docs/reels_viral_playbook.md`: плашка с 0 с, первый бит длинный, одно звуковое событие,
луп, комментарии от узнавания/изъятия информации, ноль хэштегов. Занесение вещи всегда **в один шаг**.
Лица детей не показываем; генерация — с меткой ИИ, не как UGC. Хук называет сегмент или его момент.

**Сейчас (решение работает):**
1. **С4 «Трое детей — один шкаф»**: пакеты с подписанными размерами и Excel → передача вещи младшему
   в одно касание + история «носили двое». Гейт: «таблица размеров по возрастам — в первом комментарии».
2. **С4/С3 «Сколько стоит детский шкаф за сезон»**: статистика трат по каждому ребёнку → «вот куда ушли деньги».
3. **С3 «Опять просит купить с WB»**: ребёнок присылает ссылку → родитель решает в приложении → вещь сама
   в гардеробе (после капа напоминаний 🐞).
4. **С1 «Посчитала, сколько висит с бирками»**: вставка ссылки WB → цена → итог (импульсные покупки).
5. **С6 имиджевый «Гардеробная на 400 вещей»**: статусы химчистка/ремонт у каждой вещи.

**После доделок (🟡 → ✅):**
6. **С1 «Образ на работу готов, пока ты спишь»** — нужен рабочий стилист + погода.
7. **С5 «Театр в пятницу — что надеть»** — образ по поводу из своих вещей.
8. **С2 «Собрала мужа на корпоратив за минуту»** — образ мужу из его профиля.

**После постройки (🔨, рилс = анонс):**
9. **С3 «Какой у неё сейчас размер?»** — крупнейший спрос; размер ребёнка ↔ вещь, «что стало мало».
10. **С5/С2 «Чемодан на неделю из 12 вещей»** — сборы в поездку, чек-лист, образы по дням.
11. **С2 «Мы в парных образах»** — парные образы.
12. **С4 «Разобрала выросшее за 10 минут»** — мало и не носится → объявление на Авито.

## 4. Бэклог продукта (боль × объём)

1. 🐞 Кап напоминаний совместных покупок (74 на 2 запроса) — баг, до любого рилса про покупки.
2. 🐞 Починить AI-стилиста на проде; погода и город пользователя.
3. Онбординг пустого шкафа: вместо стилиста — загрузка пачкой (главная причина оттока в нише).

7. «Выросшее → Авито» + массовая передача пачкой (средний, С4). 8. Сборы в поездку: чек-лист + образы по

11. Удаление фона (средний).
12. Импорт истории WB (большой, отдельное решение).

## 5. Открытые вопросы

- Директива фокуса держит «семью» на паузе — разморозка ветки 1 под рилсы за владельцем.
- Instagram в РФ требует VPN: сегменты 1 и 2 (особенно 40+) может быть дешевле брать в VK Клипах.
- Реальных цифр RU-Reels по хештегам #разборгардероба / #капсульныйгардероб нет — прогон `reels-trend-scout`.
- Детский хук строить на «размер», не «на вырост» (10 показов против ≈21k).
