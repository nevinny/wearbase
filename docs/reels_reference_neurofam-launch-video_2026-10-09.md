Источник — mp4, который владелец скачал и прислал (`AQMeKe1_BLsnB…GI.mp4`): 720×1280, 30 fps, 64.6 с, со звуком.

Главное в разборе — **метод** (§1). Форма ролика вторична и описана коротко (§2).

## 2. Форма ролика (кратко)

**Хук, 0–3.5 с.** Говорящая голова, жест рукой, петличка в руке. Звук — с 0.0 с:
«Opus 5.5 делает безумные видео в стиле запуска продукта, но любой, кто говорит, что он делается по одному промпту, тебе врёт».

Плашки:
- 0–1 с — «OPUS 5.5», белым, около 13% высоты кадра;
- с 1 с добавляется вторая строка «ДЕЛАЕТ БЕЗУМНЫЕ ВИДЕО / В СТИЛЕ ЗАПУСКА ПРОДУКТА», слова после «/» — красным;
- с 3.5 с — «ПО ОДНОМУ ПРОМПТУ? / ТЕБЕ ВРУТ», слова после «/» — красным.

Заголовок на ~13% высоты — в пересчёте на 1920 это ~255 px, то есть **внутри верхней UI-зоны IG** (0–300 px).
Вторая строка — на 18–21%.

Формула хука — **развенчание**: модное обещание («по одному промпту») + «тебе врут» + обещание правды.

**Структура по битам:**

| Время | Экран | Звук |
|---|---|---|
| 0–6.5 | Голова на весь кадр + хук-плашки | хук, «тебе врёт» |
| 6.5–12 | Сплит: сверху тёмная панель «6 — ШАГОВ LAUNCH-ВИДЕО», карточка «1 промпт» перечёркивается, следом примеры роликов; снизу голова | «…всегда через эти 6 шагов. Запоминай» |
| 12–21.5 | `01 — РЕФЕРЕНСЫ, НИКОГДА НЕ С НУЛЯ` | шаг 1 |
| 21.5–29.9 | `02 — ИНСТРУМЕНТЫ` | шаг 2 |
| 29.9–38.4 | `03 — НАСТОЯЩИЕ КОМПОНЕНТЫ` («ИИ-мусор» перечёркнут → 21st.dev) | шаг 3 |
| 38.4–46.1 | `04 — ПРОМПТ И РЕФЕРЕНСЫ` (текст промпта печатается) | шаг 4 |
| 46.1–50.0 | `05 — РАСКАДРОВКА` (6 экранов) | шаг 5 |
| 50.0–61.0 | `06 — ДОРАБОТКА: САМЫЙ ВАЖНЫЙ ШАГ` (v1/v2 с ярлыками дефектов, голосовое) | шаг 6 |
| 61.0–64.6 | Голова на весь кадр, плашка «НАПИШИ В КОММЕНТАРИЯХ / ХАЙП» (12–22% высоты, частично в UI-зоне) | CTA |

**Что держит внимание:**
- открытая петля «6 шагов» — счётчик объявлен на 7-й секунде;
- нумерованные главы `01…06`, каждая около 8 с;
- пословный кинетик-субтитр крупно по центру (~47% высоты) — одно слово, синхронно речи;
- непрерывная речь;
- «запоминай» — подталкивает к сохранению.

Склеек почти нет: ритм задают смены карточек и субтитр, а не монтаж.

**Почему может работать.** Развенчание модного обещания плюс конкретный нумерованный чек-лист — это контент
«на сохранение». Комментарий-гейт добавляет комментарии. **Где слабо:**
- 64 с держатся только на голосе;
- хук и CTA частично под интерфейсом IG;
- CTA не говорит, что придёт.

Метрик нет — проверить не можем.

## 3. Что переносится на наш конвейер

Шаблоны, без голоса, 1080×1920, плашка 0.48–0.63 высоты.

1. **Хук-развенчание «X? Не выйдет»** — переносим. Но мишень — убеждение самого зрителя или распространённый совет,
   а не чужое приложение (grounded-only в `smm-marketer`). «Тебе врут» не берём: это обвинение без адресата,
   и 12-летний не поймёт, кто врёт. Вместо него — «Не выйдет» или «Не спеши».
2. **Объявленный счётчик шагов + нумерованные титулы** — переносим как облегчённый `chapters` (плейбук §7.3):
   3 шага, а не 6. Без голоса 6 глав не удержат. Титул шага — цифра + 2–3 слова, крупно.
3. **Ярлык дефекта на версии** (приём для нашего процесса, не для кадра) — в `reels-director`, §5.
4. **Комментарий-гейт** — только с честным наполнением (правило шаблонов).

### Кандидат 34. Шкаф за выходные? Не выйдет
- **Сегмент:** С1/С3 · **Боль:** «Решила завести все вещи в приложение за выходные — бросила на десятой».
- **Статус:** ✅ вставка ссылки WB → карточка с ценой (№1); фото чека в карточке (№32); журнал носки по фото образа (№6).
- **Формат:** chapters-lite ≈14 с + CTA · **Задача:** saves.
- **Реф:** neurofam (этот разбор): развенчание «по одному промпту? тебе врут» → объявленный счётчик → нумерованные шаги.
- **Хук:** «Весь шкаф за выходные?» / «Не выйдет» — развенчание собственного плана зрителя.
- **Биты:**
  - 0–3.0 — открытый шкаф, гора вещей на кровати (без людей) — хук
  - 3.0–4.5 — та же кровать, одна вещь отложена в сторону — «3 шага по одной вещи»; затем 0.5 с тишины
  - 4.5–6.0 — титул «1 · Купила — ссылка»
  - 6.0–7.5 — запись экрана: карточка вещи по ссылке WB с ценой — без плашки поверх цены
  - 7.5–9.0 — титул «2 · Чек — фото»
  - 9.0–10.5 — запись экрана: фото чека в карточке вещи
  - 10.5–12.0 — титул «3 · Надела —» / «отметь» (две строки, ≤22 знаков)
  - 12.0–14.0 — запись экрана: журнал носки — «Ношу {N} из {M}» (реальные N/M из демо-гардероба)
  - 14–16 — кадр 1 — хук
- **Поворот/решение:** не переносить весь шкаф разом: новую вещь добавляешь, когда купила; надела — отметила в журнале носки (он работает только для вещей, которые уже в гардеробе).
- **Луп:** гора вещей, плашка хука.
- **CTA:** «Не разбирай весь шкаф. Купила — добавь в WEARBASE, надела — отметь.» / «Через месяц увидишь, что носишь.» → «Ссылка в профиле» · 4.5 с — экран-пояснение на размытом последнем кадре продукта, перед лупом.
- **Подпись:** «План „заведу весь шкаф за выходные“ заканчивается на десятой вещи. Есть способ проще». Последняя строка — «Кадры шкафа созданы с ИИ», если кадры FLUX.
- **Гейт:** нет (честно наполнить директ нечем сверх CTA).
- **Кадры:** дом — шкаф и кровать с вещами, без лиц; PWA — карточка по ссылке WB, фото чека, журнал носки. {N}/{M} — только реальные.
- **Пробел сюжета:** шаг 1 (ссылка WB) — только для новых покупок; старые вещи из шкафа добавляются обычным путём, по одной. Плашки не обещают, что журнал носки сам заводит вещь.
- **Риск 12-летнего:** титулы шагов ≤4 слов, каждый на отдельном кадре; три записи экрана — сразу крупно на нужный блок.

### Кандидат 35. Выросло — не выбрасывай
- **Сегмент:** С4 · **Боль:** «Советуют: выросло — раздай или выкинь. А через год младшему нужна та же куртка».
- **Статус:** ✅ метка «мала — ждёт передачи» (№18); передача между детьми с историей (№17); передача вне семьи с записью «кому» (№31).
- **Формат:** chapters-lite ≈12 с + CTA · **Задача:** saves + shares.
- **Реф:** neurofam: развенчание распространённого совета → счётчик → шаги.
- **Хук:** «Выросло — выкинь?» / «Не спеши» — развенчание совета.
- **Биты:**
  - 0–3.0 — пакет детской одежды у двери, сверху куртка (без детей) — хук
  - 3.0–4.0 — «3 шага»; затем 0.5 с тишины
  - 4.0–5.2 — титул «1 · Мала — отметь»; 5.2–6.4 — запись экрана: вещь с меткой «мала — ждёт передачи»
  - 6.4–7.6 — титул «2 · Младшему»; 7.6–8.8 — запись экрана: история вещи с передачей между детьми
  - 8.8–10.0 — титул «3 · Чужим —» / «запиши кому» (две строки); 10.0–11.2 — запись экрана: «Передача вне семьи» с заметкой
  - 11.2–13 — кадр 1 — хук
- **Поворот/решение:** вещь не теряется — понятно, что мало, кому досталось и где теперь.
- **Луп:** пакет у двери, плашка хука.
- **CTA:** «Выросло — отметь в WEARBASE, что мало,» / «и передай младшему: покупать заново не придётся.» → «Ссылка в профиле» · 4.5 с.

- **Гейт:** нет; комментарии-признания.
- **Кадры:** дом — пакет одежды, куртка (только вещи и руки); PWA — три экрана выше. «Отметь» в плашке 1 — глагол, не название кнопки; если ревью сочтёт его интерфейсным, заменить на «1 · Стало мало».

## 6. Что НЕ переносится

- **Говорящая голова, сплит «панель + лицо», пословный субтитр под речь** — требуют съёмки или голоса. Голосовая
  ветка шаблонов — в плане (vasinki №9). Лиц детей и «говорящих» ИИ-персон не делаем.
- **64 с длины.** Без непрерывной речи длина у нас проигрывает (плейбук §2, «Длина без голоса»).
- **6 шагов.** В слайдшоу держим максимум 3 главы.
- **«Тебе врут».** Обвинение без проверяемого адресата не проходит grounded-only.
- **Плашки в верхних 300 px.** У рефа заголовок и CTA частично под UI IG, у нас позиция 0.48–0.63.
- **Пустой комментарий-гейт** («напиши ХАЙП» без обещания, что придёт).
- **Скелет launch-видео «хук → продукт → фича 1 → фича 2 → цифры → лого»** — это презентация функций.
- **Remotion/HyperFrames/21st.dev** — наш HTML→ffmpeg-рендер уже закрывает задачу.
