# Consent remote-стилиста и персонализации

## Граница

Локальная модель может собрать образ без передачи данных внешнему провайдеру. Remote-вызов и
использование истории реакций разрешены только при активном `personalization` consent владельца
гардероба (`profileSubject`), а не пользователя, который нажал кнопку.

- взрослый выдаёт и отзывает согласие только для себя;
- для профиля с ролью `child` это делает родитель той же семьи;
- ребёнок не может выдать согласие себе или другому профилю;
- после revoke learning context сразу становится пустым;
- ошибка local-модели без consent возвращается пользователю и не запускает silent remote fallback.

Переход ребёнка во взрослый профиль по-прежнему вызывает общий revoke всех прежних родительских
согласий. Новое взрослое согласие не восстанавливает ранее разрешённую обработку фото.

## Минимальный remote payload

Во внешний prompt входят только:

- свободный запрос, который пользователь явно отправляет стилисту (до 300 символов);
- агрегированный learning context при действующем consent;
- для каждой вещи: одноразовый порядковый ID, категория, цвет, сезон и стили.

Не передаются фото, имя владельца, email, дата рождения, семейные связи, название вещи, материал,
заметки, URL товара и database ID. Одноразовые ID сопоставляются с сущностями только внутри запроса.

## Не входит в этот срез

Shared learning, embeddings, weather и обучение общей модели требуют отдельных consent и PR.
