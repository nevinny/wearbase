## Суть

Один реальный бренд лежит в каталоге двумя записями, обе страницы отдают 200:

| id | slug | состояние |
|---|---|---|
| 266 | `murkafam` | 100 ключевиков, 6 картинок, 4 ссылки (murka-shop.ru, IG/VK/TG), desc 623 симв., город Москва, `published_at` NULL |
| 2779 | `aleksandr-murka` | забран владельцем (client 64, claim #13, free-trial до 2026-12-03), desc 3565 + anons, email+телефон, 1 ключевик, 0 картинок, 0 ссылок, 0 товаров, опубликован 2026-08-20 |

Что это одна компания: `murka-shop.ru` отдаёт `<title>Александр Мурка</title>` и description «MURKA — бренд одежды из Луганска переехавший в Москву». `published_at` NULL страницу не скрывает — 266 тоже живая.

## Почему это важно

Владелец забрал только одну из двух живых страниц своего бренда: вторую он не видит в ЛК и не может править. Плюс дубль контента в индексе.
