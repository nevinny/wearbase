# WEARBASE — оффер услуги размещения + плейбук холодной продажи

**Создано:** 2026-06-22
**Назначение:** зафиксировать прайс услуги, текст оффера и готовые шаблоны холодного касания
для первых продаж. Экономика — [`monetization_economics.md`](monetization_economics.md);
позиционирование/враг/движение — [`marketing_strategy.md`](marketing_strategy.md);
ФЗ-38-нюансы рассылки — [`marketing_email.md`](marketing_email.md).
Список первых кандидатов — `_docs/cold-sales-candidates.csv` (50 шт., критерии в §6).

> Почему услуга, а не подписка-первой: подписка 3000₽/мес не продаётся холодным (бесплатна у
> конкурентов, нужен триал и удержание). Услуга даёт **кэш сразу**, прогрев бренда и повод для
> апселла. Логика — [`marketing_reality_check.md`](marketing_reality_check.md) §5.

---

## 1. Зафиксированный прайс

| Продукт | Цена | Тип |
|---|---|---|
| **«Размещение под ключ»** | **5 000₽** | разово |
| Апселл → подписка Basic | 1 500₽/мес | recurring (1-й мес бесплатно) |
| Апселл → подписка Premium | 3 000₽/мес | recurring (1-й мес бесплатно) |

Первый месяц подписки бесплатно — себестоимость ≈0, это убирает барьер «платить за непроверенное»
(см. экономику §7.1). Скидку на услугу при разовой оплате 3+ брендов (агентство/шоурум) — по ситуации.

## 2. Что входит в «Размещение под ключ» (5 000₽)

- **Готовая карточка бренда на WEARBASE** из реальных фактов (RAG уже сгенерил) + публикация и индексация.
- **SEO-описание + ключевые факты + FAQ** под брендовые запросы.
- **Размещение в 10+ каналах прямой дистрибуции:** бесплатные каталоги рос-брендов
  (Localbrands.pro, russian-brand.ru, Russian Streetwear Club, productcenter.ru), витрина WEARBASE,
  анонс в Telegram/VK WEARBASE.
- **Бейдж «Прямой бренд»** для соцсетей/упаковки.

**Что НЕ входит — by design:** маркетплейсы (Wildberries/Ozon/Lamoda). Мы не размещаем у
«арендодателя», против которого стоим (strategy §7.4). Это часть оффера, а не пробел.

## 3. Позиционирование (как продавать)

Якорим не против «бесплатного каталога», а против **расходов бренда, которые он уже несёт**
(Prospect Theory — якорь + loss aversion):

> «Маркетплейс забирает 30–67% с каждой продажи. Яндекс.Директ — десятки тысяч в месяц.
> Мы за **5 000₽ один раз** собираем тебе карточку и расставляем по всем прямым каналам,
> где тебя ищут, — кроме маркетплейсов. Дальше клиент твой, выручка твоя.»

## 4. Шаблон холодного касания (email)

> ⚠️ ФЗ-38: это **B2B-оффер конкретному бренду**, не массовая реклама. Каждое письмо —
> персональное (имя бренда + ссылка на УЖЕ готовую карточку), обязателен явный opt-out.
> Двухстадийный cold/warm-гейт — в [`marketing_email.md`](marketing_email.md). Не слать повторно
> тем, кто отписался/не ответил >2 раз.

**Тема:** Сделали карточку {{бренд}} — посмотрите

```
Здравствуйте!

Мы собираем каталог российских брендов, которые продают напрямую, без маркетплейсов.
{{бренд}} уже попал к нам — вот готовая карточка с описанием и фактами о вас:
{{catalog_url}}

Если хотите, доведём её до ума и разместим вас в 10+ прямых каналах (каталоги
российских брендов, наша витрина, анонс в Telegram/VK) — всё, кроме маркетплейсов.
Разово 5 000₽, дальше клиент и выручка остаются вашими.

Интересно — отвечу деталями. Если нет — просто напишите «не надо», больше не побеспокою.

{{подпись}}
```

Для брендов с `email_matches_site=no` (free-mail) — то же письмо, но первым делом проверить,
что адрес живой/бренда (а не агрегатора).

## 5. Процесс (воронка) и метрика

1. Отобрать партию (см. §6) → ручная вычитка 1 мин (выкинуть не-одежду/иностранцев).
2. Персональное письмо по шаблону §4. ~10–15/день руками.
3. Ответил → показать карточку → закрыть на 5 000₽ → разместить → апселл подписки (1-й мес free).

**Метрика — конверсия в ПЛАТЁЖ, не в ответ/регистрацию** (reality-check §4). Первая партия 50 →
цель: **≥1 платящий** (опровергает/подтверждает монетизацию дешевле любой стратегии,
действие #7 из [`big_player_roadmap.md`](big_player_roadmap.md)). База: 50k₽/мес реалистичен при
конверсии ~1,5% по всей базе контактов (экономика §6).

## 6. Список кандидатов (`_docs/cold-sales-candidates.csv`, 50 шт.)

Критерии отбора (запрос в `_docs/export_candidates.php`):
`status='new'` (лид, не зарегистрирован) · `contact_status='enriched'` + есть email ·
RAG-контент `done` + `grounded=1` (карточка реально готова к показу) · есть свой сайт ·
**источников 4–15** (отсекает и тощие, и брендов-гигантов с 30+) · есть соцсеть (IG/VK/TG —
признак DTC) · присвоен стиль (значит одежда). Сортировка по `top_retrieval_score` (качество
контента). Денилист агрегаторских доменов в email (zoon/2gis/МП).

**Флаг `email_matches_site`:** `yes` — домен email = домен сайта (высокая уверенность в контакте),
`no` — free-mail/несовпадение (проверить адрес перед отправкой). В партии 25/25.

⚠️ **Нужна ручная вычитка ~3–5 строк** — автофильтр не ловит: не-одежду (напр. Remington),
иностранные бренды (Ancient Greek Sandals, INSULAR). Выкинуть их перед отправкой.
```bash
php _docs/export_candidates.php   # перегенерить/расширить (LIMIT, критерии — внутри; пишет _docs/candidates.csv)
```
