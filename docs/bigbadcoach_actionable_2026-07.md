## Ранжир по ROI (benefit ÷ investment)

### 1. Диверсификация мест размещения вместо стеклования в один канал
**Что:** Не стройте стратегию вокруг одного источника трафика (маркетплейс, директ, соцсеть). Разные люди ищут по-разному в разных местах. Потеря одного канала = потеря половины аудитории.

**Источник:** ID 467  
**Применение к WEARBASE:** Сейчас основной рычаг = органический SEO (ищут в Яндексе/Google). Вторичный = Yandex Metrica/analytics. Добавить:
- Каталоги (2ГИС, Avvo, Trustpilot-аналоги для моды)
- Telegram-каналы (реджист в сообществах брендов одежды)
- Pinterest (визуальный рефер для женских брендов)
- Marketplace каталоги (Wildberries, Ozon — уже есть бренды)

**Вложения:** ~2–4 часа на исследование/пилот на каждый канал; 0 ₽.  
**Payoff:** +20–30% дополнительного трафика + устойчивость к алгоритмическим изменениям.

---

### 2. Статьи, которые продают: информационные запросы как мост к коммерческому интенту
**Что:** 80% поиска = информационные запросы («как выбрать бренд», «где купить экологичную одежду»). Они не конвертят напрямую, но те же люди вернутся к коммерческому вопросу. Заполняйте информационные ниши — пока конкуренты экономят.

**Источник:** ID 494  
**Применение к WEARBASE:** Кейс внутри каталога:
- «Как выбрать бренд одежды по фигуре» → ссылка на 3–5 брендов в каталоге
- «Российские бренды vs импортные: сравнение» → в каталог, в рейтинги
- «Как купить осетину по цене — гайд» → упоминание брендов с best price
- SEO-заголовки по Wordstat: встроить в карточки брендов

Потенциал: 100+ информационных ключей со спросом от 100 до 10k/мес (сейчас перекрыто лишь на 5–10%).

**Вложения:** Зачитать существующие описания брендов как статьи (0 ₽), структурировать в блоге на 1–2 ч/день, затем генерация LLM-улучшений (free local ollama).  
**Payoff:** +30–50% дополнительного органического трафика за 2–3 месяца (не конкурентная ниша = быстро ранжируется).

### 3. Размещение на high-trust доменах через биржи фриланса (1000–1500 ₽ за гарантированный ТОП SEO/GEO)
**Что:** Яндекс/Google доверяют сайтам вроде VC, Habr, Reddit. Разместить статью о вашем проекте на таком доме = гарантировать появление в ТОП за 1–2 дня. Фриланцеры на Kwork/Fl.ru имеют оплаченные премиум-аккаунты и могут разместить за 1000–1500 ₽.

**Источник:** ID 542  
**Применение к WEARBASE:** 
- Статья: «Топ-10 российских брендов, на которые ищут в Google и Яндексе»
- Разместить на: Habr (tech-фокус, но мода = тренд), VC (бизнес-углик, монетизация каталога), Medium (глобальный достаток)
- На каждый доменом = +1–2 позиции в GEO при высокой релевантности

**Вложения:** 1500 ₽ × 3 площадки = 4500 ₽ один раз; 2 часа на текст.  
**Payoff:** Быстрое появление в AI-ответах Яндекса (Алиса) = +200–500 clickthrough/мес из GEO. ROI = 30–40x за 1–2 месяца.

### 4. Заполнение Yandex-профиля для автоматического появления в AEO
**Что:** Заполните на Яндекс.Запретыче свой/бренда профиль: реальное имя в заголовке, опыт, компании, ссылки. Яндекс автоматически натягивает в нулевой блок (AEO) и в GEO-ответы.

**Источник:** ID 486  
**Применение к WEARBASE:**
- На каждого founding member / куратора WEARBASE — личный Запретыч-профиль (реальные имена, фото, опыт в моде)
- На сам WEARBASE — корп-профиль с описанием, медиа, примерами брендов
- Ссылка на каталог в шапке профиля

**Вложения:** 1–2 часа на заполнение × 2–3 профиля = 0 ₽.  
**Payoff:** Автоматическое появление в нулевом блоке Яндекса по запросам типа «российские бренды одежды» = +100–300 ежедневных кликов из нулевых блоков.

### 5. Партнёрский маркетинг с некомпетирующими брендами
**Что:** Объединитесь с брендами, которые дополняют ваш каталог (обувь + одежда, аксессуары + платья). Обменивайтесь рекомендациями, кросс-промошьте, разделите бюджеты контента, упоминайте друг друга.

**Источник:** ID 576  
**Применение к WEARBASE:**
- Договорённость с 3–5 дополняющими брендами: кросс-ссылки в блоге
- Совместные статьи: «Как подобрать обувь под платье» (бренд обуви + WEARBASE)
- Распределение в соцсетях друг друга — реки комментариев без денег
- Referral-программа: рекомендуем в каталоге друг друга, оба получают трафик

**Вложения:** ~3 часа на поиск + переговоры; 0 ₽ (взаимный обмен).  
**Payoff:** +15–25% трафика + authority boost (упоминания на авторитетных сайтах = ссылки без денег).

### 6. Yandex Webmaster для отслеживания видимости в AI-ответах
**Что:** В Yandex Webmaster появилась функция отслеживания видимости в Алиса AI и GEO. Видите, по каким запросам вы есть/нет в AI-выдаче, и какие конкуренты там доминируют.

**Источник:** ID 527  
**Применение к WEARBASE:**
- Ежедневно смотреть: по каким запросам появляемся в Алиса, по каким нет
- Составить gap-лист: где есть спрос, но нет нас
- Написать статьи по этим запросам (см. пункт 2)

**Вложения:** 10 мин/день на мониторинг; 0 ₽.  
**Payoff:** Проактивное заполнение дыр = +10–20% трафика из GEO без платных работ.

### 7. Структурирование сайта через mind-maps перед разработкой
**Что:** Не сразу лезть в CMS/конструктор. Нарисуйте в Google Sheets (или xMind) иерархию: главная тема → подтемы → каждой подтеме = отдельная страница под конкретный поисковый интент. Это гарант того, что сайт ранжируется.

**Источник:** ID 490  
**Применение к WEARBASE:**
- Главная тема: каталог российских брендов одежды
- L2 (тип): премиум-бренды, бюджетные, экоосознанные, локальные, винтаж
- L3 (по материалу): льняные, шерстяные, хлопковые
- L4 (по типу одежды): платья, рубашки, пиджаки
- Каждая страница = один поисковый интент (семантика + Wordstat)

**Вложения:** 4–6 часов на map один раз; затем LLM автоматизирует title/meta.  
**Payoff:** Структура из 500+ страниц вместо 50; +200–300% ожидаемого трафика.

### 8. Экспертный контент не лайкают, сохраняют: не гонитесь за метриками
**Что:** Когда вы пишите статьи про SEO/бизнес, люди не ставят лайки (видимость падает). Но они сохраняют, репостят в закрытые чаты, отправляют друзьям. Метрика = saves + shares, не likes.

**Источник:** ID 543, 530  
**Применение к WEARBASE:**
- Отслеживать не likes, а clicks + saves + shares в Яндекс.Метрике
- Писать статьи на боль: «Как выбрать при ограниченном бюджете», а не лайк-ловушку
- Ожидание: 50 likes → 200 saves = на самом деле это вирт

**Вложения:** 0 ₽; переформатирование мышления.  
**Payoff:** Спокойствие при пилоте контента; правильные решения о выборе тематик.

### 9. Частотность постинга меньше, чем качество
**Что:** Тест: месяц без видео. Результат = никакого падения. Люди подписаны не на графики, а на качество. Один качественный пост в неделю > 7 посредственных.

**Источник:** ID 545  
**Применение к WEARBASE:**
- Вместо ежедневного постинга: 2–3 крупных статьи в неделю
- Каждая статья = полноценный SEO-контент, не тизер
- Освобождение времени на глубокое копирайтинг

**Вложения:** 0 ₽; отмена страха daily postings.  
**Payoff:** Лучше ранжируются; меньше burnout; выше конверсия.

### 10. Community/Экосистема для peer-learning и распределения работ
**Что:** Создайте закрытое сообщество (Telegram, WhatsApp, paid Notion). Там: еженедельные case study вебинары, peer-to-peer помощь, доска с поиском специалистов. Community сам себя обслуживает (контент создают участники).

**Источник:** ID 514, 495, 466, 475  
**Применение к WEARBASE:**
- Вебинары: «Как я растил свой бренд» (раз в неделю, 30–50 участников max)
- Case studies: берёте 2–3 бренда из каталога, разбираете на стриме их SEO/growth
- Community members сами начинают предлагать контент (тейк со статьи 466 ID)
- Доска заказчиков/исполнителей для контента, дизайна, SMM

**Вложения:** 3–5 ч/неделю на модерацию; опционально платная подписка (Notion: $10–50/мес).  
**Payoff:** 
- +50% трафика из рекомендаций (участники приводят друзей)
- Бесплатный контент (члены сообщества пишут case studies)
- Рычаг монетизации (продажа движка как услуги через community социалу + trust)

### 11. Анализ link profile конкурентов через Ahrefs для копирования успешных стратегий
**Что:** Возьмите 3–5 конкурентов из ТОП SEO, закиньте в Ahrefs, посмотрите: откуда к ним ссылки? На каких сайтах они упоминаются? Логика: если конкурент получает ссылки с площадки X, туда же сможете попасть и вы.

**Источник:** ID 562  
**Применение к WEARBASE:**
- Конкуренты: Lyst, Brandshop.ru, Vitrine.market (аналоги)
- Выгрузить их ссылочные профили
- Таблица: источник → тип контента → как туда попасть
- Повторить 30–50% самых простых ссылок (агрегаторы, каталоги, пресс-релизы)

**Вложения:** $9–99/мес Ahrefs (или free trial); 3–4 часа анализа.  
**Payoff:** +20–40% дополнительных ссылок за 3–6 месяцев = +15–25% рост органического трафика.

### 12. GEO = автоматический результат хорошего SEO (не требует отдельной стратегии)
**Что:** Стремитесь попасть в AI-ответы? Забудьте. Просто делайте хорошее SEO: авторитет, свежесть, relev-ность. Яндекс сам натягивает топ-SEO результаты в GEO. Отдельная стратегия для GEO = пустая трата времени.

**Источник:** ID 506, 472  
**Применение к WEARBASE:**
- Не писать контент специально для AI
- Оптимизировать под SEO, E-E-A-T, свежесть
- Мониторить GEO через Webmaster (пункт 6)
- Результат = сам появитесь в GEO через 2–4 недели

**Вложения:** 0 ₽ доп; просто правильный SEO.  
**Payoff:** +30–50% трафика из GEO как побочный эффект SEO (органически).

### 13. На конференциях/events говорите о боли, а не раздавайте мерч
**Что:** Люди приходят узнать, как вы решаете их проблему. Если вместо ответа раздаёте пакеты — они уходят. Нужно: персональное общение → понимание боли → предложение решения.

**Источник:** ID 483, 482  
**Применение к WEARBASE:**
- Если на выставках моды / конференциях брендов:
  - Стенд с вопросом: «Какой тип бренда вам не хватает в каталоге?»
  - Не демо платформы, а интервью владельцев
  - Контакты → follow-up письмо с кейсом

**Вложения:** 8–16 ч на стенд; возможно ~5–10k ₽ на место (опционально).  
**Payoff:** +10–30 qualified лидов (бренды, уже готовые присоединиться).

## Пропущены / не подходят

- **Курсы и платные продукты**: Coach их не продаёт, но часто упоминает. Для WEARBASE не приоритет в июле.
- **Личный бренд founder'а**: Стратегия интересна, но требует 5–10 ч/неделю на контент. Если нет dedicated founder — отложить.
- **Crypto/blockchain маркетинг**: Вне ниши.
- **Коллаборации с блогерами на TikTok/IG**: Дорого; для WEARBASE моды лучше работает SEO + внутренняя комьюнити.

## Приоритизация на Q3 2026

1. **Неделя 1–2**: Структура каталога (mind-map) + инвентаризация информационных ключей → 200+ новых страниц.
2. **Неделя 3–4**: 3 статьи на Habr/VC (4500 ₽ Kwork) + заполнение Запретыч-профилей.
3. **Месяц 2**: Запуск weekly case study вебинаров (community pilot).
4. **Месяц 2–3**: Ahrefs анализ конкурентов, повтор 30% их ссылок.
5. **Ongoing**: Мониторинг GEO в Webmaster, заполнение gap-листа.

**Ожидаемый результат к концу Q3:** +50–100% органического трафика, 10–50 юрлиц в очереди на оформление.
