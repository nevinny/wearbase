# Рефы: whatships.com (launch-видео) + оценка 21st.dev (2026-10-09)

Повод: владелец — «референсы не добавлены. whatships.com … 21st.dev?». В разборе neurofam
(`docs/reels_reference_neurofam-launch-video_2026-10-09.md`, шаги 1 и 3) оба сайта отметили «уже есть»,
не открывая их. Здесь они открыты, просмотрены и выгружены.

**Коротко:**
- **whatships.com** — бесплатный курируемый каталог launch-видео стартапов из X/Twitter. На 08.10.2026 в нём
  2 447 роликов. Формат каталога — X, а не Reels: из 144 роликов категории Consumer вертикальных 17,
  строго ~9:16 — только 9. Значит, рефы отсюда — источник **драматургии и монтажных приёмов показа
  приложения**, а не готовой вертикальной формы. Отобрано и скачано 15 рефов, ~120 МБ:
  `~/seo-archives/whatships-refs/`.
- **21st.dev** — маркетплейс React/Tailwind/shadcn-компонентов (12 000+) и MCP-сервер (бывший Magic MCP).
  Полезен узко, как **источник паттернов** для плашек, CTA-экрана, рамки телефона и кинетик-текста.
  Код — React, а наши кадры — ванильный HTML и canvas через Playwright, так что компоненты придётся
  переписывать вручную, а не ставить. Ставить MCP сейчас не нужно (см. §5).

## 1. whatships.com — что это

- **Что это.** «Independent, curated directory of startup launch videos, demos, and walkthroughs shared on X».
  У каждой записи есть страница `/videos/{slug}/` со ссылкой на оригинальный пост в X.
  Исходники сайта открыты: github.com/dingyi/whatships.com. Сайт бесплатный, без аккаунта и платного размещения.
- **Категории** (у видео по одной): AI · Developer tools · Design · Motion · Productivity · Consumer · Hardware · Other.
  Тегов-фильтров нет, есть поиск. Нет ни фильтра по формату (9:16), ни деления на «mobile app».
  Длительность указана на странице видео, разрешение — нет (мы снимали его через `yt-dlp --skip-download`).
- **Машинный доступ:** `/llms.txt`, `/llms-full.txt`, `/openapi.json`, `/search-index.json`
  (2 447 видео, 95 инструментов, 11 студий). Страницы отдают markdown по `Accept: text/markdown`.
  MCP нет. Есть ещё разделы `/tools/` (редакторы, mockup-инструменты) и `/studios/` (моушн-студии).
- **Consumer — 145 роликов.** Это в основном финтех/крипта, соцсети, игры и утилиты. Детских, семейных
  и гардеробных продуктов почти нет. Ближайшие по теме — neatlogs (семейный чат → календарь),
  Paww (приложение «заботы о ком-то»), Cosmos (вкус/мода), Perplexity try-on (одежда), Koji (дети, категория AI).
  Полный замер разрешений Consumer лежит в `~/seo-archives/whatships-refs/_site/consumer_dims.txt`.
- **Условия (terms, 27.08.2026).** Права на видео и марки принадлежат авторам. Цитировать надо так:
  продукт + компания + запись whatships + оригинальный X-URL. Сайт прямо пишет, что он
  «не download CDN». Мы качали **из оригинальных постов X** (yt-dlp), а не через их прокси.
  Архив — **только для внутреннего изучения**: в наши ролики кадры не берём, наружу не публикуем.

## 3. Паттерны для наших рилсов

Привязка к типам кадров шаблонов (`render-template.cjs`, `TYPE_SHORT`): ФОТО / СКРИН ЧАТА / ЗАПИСЬ ЭКРАНА PWA.

1. **Запись экрана + одна плашка-тезис на одну фичу** (643 Mobile, Paww, MyPlantHealth). Тезис в 2–4 слова,
   крупно и контрастно, в нижней трети. Меняется вместе со сменой экрана. UI под плашкой не закрыт.
   У нас: бит `screen` + плашка — уже наш формат. Новое — **жёсткий лимит 2–4 слова на тезис**
   и **смена плашки строго на смене экрана**.
2. **Одна задача от начала до конца, луп в исходную точку** (Cash App, Stamply, brrr).
   Ролик 10–15 с без единого текстового кадра: «пусто → действие → результат → снова пусто».
   У нас: короткий рилс «добавить вещь ребёнка» одной записью PWA, последний кадр = первый. Это ложится
   на наш `loop`-бит. Самый дешёвый тип: нужна одна запись экрана.
3. **Кульминация — системное событие** (brrr, Tuyo): реальный пуш или реальное уведомление как «панч».
   У нас: напоминание «ребёнок вырос из размера» или «у бренда новая коллекция», если это **настоящий**
   пуш/письмо, записанный с телефона. Нарисованный пуш — нельзя.
4. **Слово-за-словом на нейтральном фоне** как связка между экранами (Cosmos, Tuyo «Maybe?»).
   Это CTA- и переходные кадры, а не замена продукта.
5. **CTA «как поставить»** — мини-туториал установки (Utapp): иконка → «Get» → «Download now».
   У нас: wearbase.ru → «Поделиться» → «На экран Домой» (реальная запись Safari/Chrome).
6. **Эмоциональная рамка «о ком ты заботишься»** (Paww): живой кадр в начале и в конце, продукт посередине,
   лозунг «Их целый мир. Одно маленькое приложение». Переносится на «гардероб ребёнка» почти дословно,
   но живые кадры — только наши реальные фото (H8).

**Не берём:** AI-кино вместо продукта (Perplexity); длинную техничную середину «как это устроено внутри» (neatlogs);
горизонталь 16:9 без перекадровки. Горизонтальные рефы берём только как драматургию.

## 4. 21st.dev — что это

- **Что это.** «Community registry of UI components and templates»: 12 000+ компонентов, шаблонов и тем.
  Стек — React + TypeScript + Tailwind + shadcn/ui (Radix). Есть «21st AI» (генерация UI по промпту),
  Design Bug Bot (дизайн-ревью PR) и поиск SVG-логотипов.
- **MCP / CLI.** «21st MCP» (бывший Magic MCP, пакет `@21st-dev/magic` ещё работает).
  Эндпоинт — `https://21st.dev/api/mcp`, ключ создаётся на https://21st.dev/mcp. Инструменты:
  - `search` — бесплатно, только метаданные;
  - `get_component` — код компонента, платно сверх лимита;
  - `get_inspiration`;
  - `search_logo`;
  - `generate` — платно.
  Тот же пакет ставит CLI `21st` для публикации своих компонентов. Есть ещё `openapi.json` и `llms.txt`;
  к страницам компонентов можно дописать `.md`.
- **Цены** (`/pricing.md`, 09.10.2026):
  - **Free** — поиск без ограничений, **2 копии/установки компонента в день** суммарно (веб + MCP + CLI);
  - **Builder** — $6/мес при оплате за год ($8 поквартально), копирование и MCP-выдача без лимита, без AI-кредитов;
  - **Builder + AI** — $15–60/мес (500–2 000 кредитов);
  - **Team** — $7,50 / $18,75 за место.
- **Лицензия — три разных слоя:**
  1. Код MCP-сервера — MIT.
  2. **Код компонента — лицензия его автора**, у каждого своя. Многие под MIT (Magic UI / Dillion Verma, Motion
     Primitives и т. п.), но проверять надо по каждому. Terms требуют сохранять лицензию и указывать автора.
  3. **Демо, превью, скриншоты и видео-превью** — собственность 21st Labs, использовать их можно только
     на платформе. Скрейпинг запрещён (раздел 3 Terms). То есть брать можно **код** по лицензии автора,
     но не их картинки или ролики.
- **Что есть под наши кадры:**
  - Text Animation — ~200 компонентов: blur-reveal, word pull-up, gradual spacing, word rotate, stagger,
    looping words на GSAP;
  - Mockup — 33, iPhone — 15: iPhone 16 Pro, iPhone Mockup, Phone Mockups;
  - Cards, Buttons, CTA- и hero-секции.

## 5. 21st.dev в нашем конвейере: вердикт

**Правило:** экран продукта — только реальная запись PWA или реальные скрины (H8). 21st.dev может дать
**обрамление**, но не **содержимое**.

| Что | Можно? | Как |
|---|---|---|
| Рамка телефона вокруг реальной записи экрана (iPhone 16 Pro mockup) | **да** | Портировать разметку и CSS рамки в `scene-template.html`, внутрь — наш `<video>`/canvas с записью |
| Кинетик-текст плашек и CTA (word pull-up, blur-reveal, word rotate) | **да** | Это CSS/JS-анимации. Переписать на ванильный JS с детерминированным временем, потому что Playwright рендерит покадрово. Хорошая замена нашим статичным плашкам для паттерна 4 |
| Кнопка/карточка на CTA-экране | **да** | Как стиль плашки, со словами о реальном действии |
| Переходы между битами | **да** | Как CSS-паттерн |
| Dynamic Island, Notification Center, chat-messages, hero с «экраном приложения», сгенерированные `generate` экраны | **нет** | Это выдуманный UI. Исключение — точная копия **реального** уведомления нашей PWA, но и тогда лучше снять настоящий пуш (паттерн 3) |

**Вердикт:** подключать MCP сейчас **не нужно**. Нам нужно 3–5 приёмов (рамка, 2–3 анимации текста,
CTA-кнопка), и их проще один раз вручную портировать в `scene-template.html` из компонентов с MIT,
указав автора в комментарии. React/shadcn в конвейер не тянем.

**Если решим подключить** (только после одобрения, ничего не установлено):
1. Ключ: https://21st.dev/mcp.
2. `npx @21st-dev/cli@latest init --client claude` — **печатает** конфиг. С флагом `--write` записывает его
   в конфиг клиента: это правка настроек, нужно согласие.
3. В конфиг подставить ключ и **держать его вне git** (их terms прямо требуют не класть ключ в публичные репо,
   а наш репо публичный).
4. На Free хватит `search`, так как он бесплатный. Для портирования — 2 копии в день; при регулярном использовании
   Builder стоит $6–8/мес.

Сырые выгрузки (`mcp.md`, `pricing.md`, `llms.txt`, `openapi.json`, terms) лежат в `~/seo-archives/21st-dev/`.

## 6. Что сделать дальше (предложение)

1. Снять в PWA одну запись «добавить вещь ребёнка» (10–15 с) и собрать по паттерну 2 — самый дешёвый A/B.
2. Перевести плашки шаблонов на лимит 2–4 слова и смену на смене экрана (паттерн 1). Это правка каталога, не движка.
3. Портировать одну рамку iPhone и одну анимацию «word pull-up» (MIT) в `scene-template.html`.
