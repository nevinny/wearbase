# Виртуальная примерочная (VTON) — PoC и руководство к запуску в прод

> Статус на 2026-06-13: **PoC доказан**. Клиент загружает фото → готовится «мастер-фото»
> (студийный фон, лицо без изменений) → примерка вещей из каталога → галерея образов.
> Работает на LLM-сервере **192.168.2.43** (ферма GPU). Прод-интеграция в wearbase ещё не сделана —
> ниже архитектура и пошаговый план.

---

## 1. Что это и как работает

Конвейер из двух стадий (требование PO: сначала подготовка, потом примерка):

```
Фото пользователя (домашнее, любой фон)
        │
        ▼  СТАДИЯ 1 — Мастер-фото (1 раз на пользователя, кешируется)
   ├─ BiRefNet-portrait      вырезка человека (волосы чисто)
   ├─ Композит на студийный градиент (стена→пол, светло-серый)
   ├─ Тень-эллипс под ногами + лёгкая полировка (яркость/контраст)
   └─ Лицо/тело — пиксель-в-пиксель из ОРИГИНАЛА (диффузия не участвует → лицо не меняется)
        │
        ▼  СТАДИЯ 2 — Примерка (на каждую вещь)
   ├─ Agnostic-маска зоны тела по типу вещи (НЕ по текущей одежде!)
   └─ CatVTON: переносит вещь из каталожного фото на мастер-фото
        │
        ▼
   Галерея «образов» (вещь × [ракурс])
```

### Ключевой инсайт (почему 2-я итерация заработала)

Маску для примерки надо строить по **зоне тела, где одежда МОЖЕТ быть** (agnostic-маска),
а **не по тому, что на человеке надето сейчас**:

- ❌ Маска текущей одежды: человек в штанах → маска-штаны → юбка натягивается на ноги, а не
  образует силуэт. Безрукавка → маска без рукавов → у футболки пропадают рукава.
- ✅ Agnostic-маска: **верх** = торс ∪ руки (обрезка ниже линии бёдер, чтобы не цеплять кисти);
  **низ** = вся область ног целиком → юбка ложится сплошным силуэтом.

Agnostic-маску строит нода `ClothesSegment` (SCHP-парсинг, 20 классов тела) — выбором классов
тела, а не одежды. **DensePose/detectron2 НЕ нужны** (и не собираются на Celeron в .43 без AVX).

## 2. Железо и стек на .43

| Компонент | Значение |
|---|---|
| GPU | 3× RTX 2060 Super (8 ГБ) + 1× RTX A4000 (16 ГБ); VTON крутится на A4000 — `CUDA_VISIBLE_DEVICES=3` |
| CPU | Intel Celeron B810 (**нет AVX** — отсюда грабли с kornia-rs, detectron2) |
| ComfyUI | `~/vton/ComfyUI`, venv с torch 2.5.1+cu121 |
| Запуск | `cd ~/vton/ComfyUI && . venv/bin/activate && CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=3 python main.py --listen 0.0.0.0 --port 8188` |
| Доступ с мака | порт 8188 закрыт фаерволом снаружи → SSH-туннель: `ssh -N -L 8188:localhost:8188 llm` |

### Custom-ноды (`~/vton/ComfyUI/custom_nodes/`)
- `ComfyUI_CatVTON_Wrapper` — примерка (нода `CatVTONWrapper`)
- `ComfyUI-RMBG` — вырезка фона (`BiRefNetRMBG`) + парсинг тела (`ClothesSegment`)
- `ComfyUI-IC-Light` — переосвещение (в PoC НЕ используется, см. §6)
- `ComfyUI-IDM-VTON` — установлена, но требует DensePose (см. §6, v3)
- `ComfyUI-Manager`

### Веса (`~/vton/ComfyUI/models/`, ~11 ГБ)
- `CatVTON/` (6.8 ГБ): attention-веса CatVTON (`mix-48k-1024`), `stable-diffusion-inpainting`
  (база, зеркало `booksforcharlie`), `sd-vae-ft-mse`, `SCHP/` (парсинг), `DensePose/` (для v3)
- `unet/iclight_sd15_fc.safetensors` (1.7 ГБ) — IC-Light
- `checkpoints/v1-5-pruned-emaonly-fp16.safetensors` (2.1 ГБ) — SD1.5 база для IC-Light

### Грабли, которые уже решены (чтобы не наступить снова)
1. **torchaudio CUDA-конфликт**: ставить строго `torchaudio==2.5.1+cu121` в пару к torch.
2. **kornia падал `Illegal instruction`**: его Rust-бинарь собран под AVX. Решение —
   `kornia==0.6.12` (чистый Python, без `kornia-rs`).
3. **`cached_download` ImportError** в diffusers-нодах: `huggingface_hub==0.25.2`.
4. **BEN2/INSPYRENET в RMBG падали `process_res`**: использовать `BiRefNet-portrait`.
5. **Sanster/SD-inpainting → 401**: брать `booksforcharlie/stable-diffusion-inpainting`.

## 3. Скрипты PoC (`~/tools/vton-poc/` на маке)

| Скрипт | Назначение |
|---|---|
| `install-43.sh` | Установка ComfyUI + все custom-ноды на .43 (идемпотентно) |
| `run-masterphoto.sh <person> <studio-bg> <face-mask> [out]` | Стадия 1: мастер-фото |
| `run-tryon-auto.sh <person> <garment> <upper\|lower\|dress> [out]` | Стадия 2 с автомаской (для same-cut) |
| `run-tryon.sh <person> <garment> <mask> [out]` | Примерка с готовой маской (для agnostic) |
| `fetch-garments.sh urls.txt` | Скачать фото вещей по списку URL |

Все ходят в ComfyUI API на `http://localhost:8188` (через туннель). Логика: upload входов →
сборка graph JSON → POST `/prompt` → опрос `/history/{id}` → скачать результат через `/view`.

## 4. Качество (итог PoC)

| Категория | Результат | Комментарий |
|---|---|---|
| Верх (футболки, свитера, куртки) | ✅ Продакшен | Рукава, планки, фактура переносятся; полностью авто |
| Низ (юбки, брюки) | ✅ Рабочий силуэт | Через agnostic-маску ног; атласный блеск приглушён |
| Платья | ⚠️ Не тестировалось глубоко | Маска `dress` готова, нужен прогон |
| Мастер-фото | ✅ Продакшен | Лицо/цвета не меняются (физический возврат из оригинала) |

Время: мастер-фото ~25 c, примерка ~50 c на A4000 (40 шагов).

## 5. План интеграции в прод (wearbase)

### 5.1 Данные
- Сущность `UserTryonPhoto`: `user_id`, `original_path`, `master_path`, `status`
  (uploaded/processing/ready/failed), `created_at`, `consent_at`, `expires_at`.
- Сущность `TryonResult`: `user_id`, `product_id`, `image_path`, `created_at`, `expires_at`.
- ПД: фото — персональные данные. **Обязательно** явное согласие при загрузке (consent-инфраструктура
  152-ФЗ в проекте уже есть) и автоудаление оригинала+мастера по `expires_at` (крон, напр. 30 дней).

### 5.2 Маска по типу товара — автоматически
Категория товара в каталоге → регион маски:
- верхняя одежда → `upper` (торс+руки, обрезка по бёдрам)
- юбки/брюки → `lower` (зона ног)
- платья/комбинезоны → `dress` (торс+ноги+руки)

То есть пользователю НЕ надо ничего выбирать — регион берётся из `category` товара.

### 5.3 Поток
```
ЛК: загрузка фото + чекбокс согласия
   → Symfony Messenger job: MasterPhotoJob (HTTP в ComfyUI API на .43, стадия 1)
   → master_path готов, статус ready
Каталог/карточка товара: кнопка «Примерить»
   → TryonJob(user, product): берёт master_path + фото товара + регион по category
   → HTTP в ComfyUI API (стадия 2) → TryonResult
   → галерея в ЛК «Мои образы»
```
- ComfyUI API дёргать с того же бэкенда, что ходит на .43 (или через Tailscale/туннель — .43 в локалке).
- Очередь обязательна: генерация 50–75 c, синхронно нельзя.
- Фото товаров: брать каталожные (чистый фон), НЕ лайфстайл с маркетплейсов (модель затаскивает
  чужие предметы в результат). Это аргумент за сбор фото товаров краулером с сайтов брендов.

### 5.4 Несколько ракурсов (требование PO)
Генерация новых поз из одного фото сегодня «плывёт» по лицу — для примерки не годится. MVP:
просить у пользователя 2–3 фото (анфас / полуоборот / спина), каждое гонять через стадии 1–2.
Капсула = сетка «образ × ракурс». Генерация поз — исследование v3.

### 5.5 Запуск .43 как сервиса
Сейчас ComfyUI поднимается руками. Для прода — systemd-юнит на .43 с автозапуском и рестартом
(аналогично рекомендации по `rag:daemon`).

## 6. Известные ограничения и v3

1. **Атлас/блеск, полный фотореализм низа** — предел CatVTON (обучен в осн. на верхе, VITON-HD).
   Апгрейд: **IDM-VTON** (установлен) или **Leffa** — держат ткань лучше, НО требуют **DensePose**
   (detectron2), который не собирается на Celeron без AVX. Нужна отдельная GPU-машина с AVX-CPU,
   либо генерация DensePose на стороне. Это v3.
2. **IC-Light переосвещение** — на полном denoise перерисовывает фон и обесцвечивает одежду.
   В PoC отключён (мастер-фото и так чистое). Для «настоящего студийного света» нужна аккуратная
   настройка denoise + DetailTransfer — отложено.
3. **Генерация ракурсов/поз** — см. 5.4, v3.

## 7. Быстрый старт (воспроизвести PoC)

```bash
# 1. Туннель к ComfyUI на .43
ssh -N -L 8188:localhost:8188 llm &

# 2. Поднять ComfyUI на .43 (если не запущен)
ssh llm 'cd ~/vton/ComfyUI && . venv/bin/activate && CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=3 \
  setsid nohup python main.py --listen 0.0.0.0 --port 8188 > ~/comfyui.log 2>&1 < /dev/null &'

# 3. Мастер-фото
cd ~/tools/vton-poc
./run-masterphoto.sh person.jpg studio-bg.png face-mask.png master.png

# 4. Примерка (верх — авто-маска)
./run-tryon-auto.sh master.png garment.jpg upper result.png
```
