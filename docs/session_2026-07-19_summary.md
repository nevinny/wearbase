# Сессия 2026-07-19 — стратегия монетизации + SEO-дожим + foreign-политика

Консолидирующий обзор большой сессии. Глубина — в связанных доках (ссылки ниже). Здесь: что решено, что сделано, что открыто.

## 1. Стратегия монетизации (главное)

Полный план: **`docs/monetization_plan_10mln.md`**. Память: `wearbase-monetization-direction`.

- **Ставка — путь B:** продавать наружу grounded-контент-движок, НЕ монетизировать бренды каталога (за год 0 платящих — модель мёртвая). Деливерабл готов (аналог ContentMagic 130к/20 статей, маржа ~94%).
- **Цель скорректирована:** не «10 млн за 90 дней», а **1 млн ₽/мес чистыми (net MRR) в долгосроке** (~9–14 мес на ретейнерах: ≈8–14 клиентов ×80–150к, либо 2–3 white-label-агентства). Мотив — заменить незащищённый фриланс-доход.
- **⚠️ Key Group / getrentacar — КОНКУРЕНТ** с похожим конвейером, НЕ клиент (обнулило «тёплый якорь», на котором строились оба стратегических прохода). Владелец там по **фрилансу (ГПХ), на своём железе, без пересечения с рабочим** → технология его, non-compete для ГПХ в РФ неприменим. Гигиена: не переманивать клиентов KG, не лезть в их вертикаль (авто/аренда), глянуть конфиденциальность/non-solicit в договоре.
- **GTM вне орбиты KG:** white-label SEO-агентствам > нишевые вертикали > холод. Приоритет — быстрый кэш (контент-пакеты/мелкие ретейнеры за дни-недели), не enterprise-«билд движка» (длинный цикл).
- Кейс-референс метода (не для копирования как курс): **`docs/roma_rayt_11mln_case.md`** (Рома Райт: 11 млн через воронку YouTube→TG + Claude-аналитика).

## 3. Fit-тест «годится ли проект для контент-завода»

Проект годится, если ВСЕ три: (1) много сущностей; (2) у каждой извлекаемые проверяемые ФАКТЫ (не мнения); (3) есть поисковый спрос. Нет п.1/п.2 → плохой фит.

Прогон тёплых проектов — **`docs/fit_test_warm_projects.md`**:
- ☕ **coffeeproservice.ru — СИЛЬНЫЙ фит.** Матрица «бренд × модель × поломка × E-код» (9+ брендов) = тысячи страниц; сейчас 0 модельных страниц и 0 кодов ошибок — программатик-слой не тронут. Граунд: мануалы, таблицы E-кодов, каталоги запчастей, логи ремонтов. Монетизация: заявки на ремонт. Ограничение: заявки Москва+МО, органика вся РФ.
- 💆 **massage-lilit.ru — НЕ фит.** Одна точка, YMYL/здоровье, спрос локальный → локальное SEO (Карты/отзывы), не завод.

## 5. Перелинковка (граф `brand_related`) — РЕШЕНИЕ ПО АРХИТЕКТУРЕ

- Механизм: статический блок «похожие бренды», out-degree 12, min in-degree 2. Тиры: `embedding` (Qdrant) → `style` → `city` → **`fill`** (произвольная добивка до 12).
- `embedding`/`style` релевантны; **`fill` — farm-like мусор** (то, что владелец назвал «хардлинки»).
- **Граф на проде НЕ считать** — это производные данные из эмбеддингов; правильно считать на Mac (где Qdrant) и **синкать таблицу `brand_related` на прод зеркалом**, как остальной генерённый контент. Прод не должен тащить Qdrant.
- Повторный инкрементальный прогон: сильные рёбра (embedding/style) стабильны, слабый тир `fill`/`city` дрейфует/перебалансируется. Полный `--rebuild` пересчитывает всё.
- **ОТКРЫТО (ждёт владельца):** оставить 12 статичных ссылок, но **убить тир `fill`** (показывать <12, только реальные совпадения)? Или уменьшить блок / сделать контекстным? Пока решения нет — граф на прод не гоним.
- foreign-рёбра из живого графа при необходимости убираются **через сервис/Doctrine (Symfony-style, с событиями), НЕ сырым SQL DELETE** — мутации не должны обходить доменную логику/lifecycle/soft-delete. Без полного пересчёта графа.

## 6. Foreign-бренды — ПОЛИТИКА (уточнена владельцем)

- Иностранные бренды **НЕ прятать** (переориентированы как якоря серии «чем заменить [бренд]», под них пишутся листиклы — намеренный SEO-актив). Ничего не скрываем, статусы не трогаем.
- **Исключить foreign из хабов ГОРОД и СТИЛЬ и из sitemap/«российских» листингов** — чтобы не выдавались за локальные российские.
- Шаблон карточки: для foreign **не писать «российский бренд»** (снять противоречие «российский… из Милан»); geo-факт (напр. Милан) оставить как факт.
- **cuvee** → пометить `origin=foreign` курированием (не галлюцинация: реально миланский, Istituto Marangoni). Не скрывать.
- Граф перелинковки: исключить foreign из кандидатов (не линкуем российские на иностранные).
- Контекст находки: origin-гейт (политика «иностранные не публикуем») в данных был, но **в `BrandsController` фильтр не был вкручен** → 33 foreign (Nike/Chanel/Cartier…) были в публичных выборках; ~31% опубликованных карточек с geo показывали иностранное производство. Гейт вкручивается (на dev, in-flight).
