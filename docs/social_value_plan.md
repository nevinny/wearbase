# Ценность в соцсетях: синтез двух независимых анализов (2026-07-10)

Метод: два независимых deep-reasoner-прогона (рамка «аудитория/ценность» и рамка
«системная: данные→контент»), без взаимного доступа, затем синтез. Входные разведки:
конвейер соц-постов (`src/Service/Social/`, `docs/marketing_instagram.md`) и
YouTube-обогащение RAG (`topic_chunks`, 715 транскриптов 5 бизнес-каналов, юзается
только советником).

## Диагноз (сошлись обе рамки)

1. **Closed-loop разомкнут** — метрики не собираются, KPI (saves·3+shares·3+linkTaps·2)
   не на чем проверять. Любая новая рубрика без этого — ставка вслепую.
2. **~43% сетки — B2B-самопиар в консюмерском фиде** (вт calculator, чт manifesto,
   пт vs_marketplace): покупателю безразличны комиссии WB/Ozon, а основатель бренда
   консюмерский канал не читает. Это и есть «рекламный шум».
3. **Нет ни одной save-утилиты** («где купить X», «чем заменить ушедших») — то,
   ради чего фэшн-контент вообще сохраняют и пересылают.
4. `brand_week` — LLM-подпись из описания = дженерик без крючка.

## Правило безопасности для YouTube-базы (ключевое, снимает 3 риска разом)

**topic_chunks → только framing/angle, никогда → факты.** Жёсткие утверждения
(цифры, факты) — только из PILLARS и `brand_chunks`. Публикуем оригинальный
парафраз голосом WEARBASE, никогда не verbatim-текст транскрипта;
`rag_citations` — внутренний провенанс, спикеров публично не называем
(нет имплицитного эндорсмента); исключение — явная отсылка к именной методологии
с честной атрибуцией. Это одновременно нейтрализует: копирайт (охраняется
выражение, не идеи), ошибки авто-субтитров (yt-dlp, не whisper!), галлюцинации.

## Роадмап (ранжирован по ценность × реалистичность)

### Фаза 0 — замкнуть петлю (enabler) — ✅ сделано 2026-07-13
UTM-клик-инжестер `app:social:ingest-clicks`: токена API Метрики нет — источник
кликов **nginx-логи прода** (ssh+zgrep, combined-формат, ретеншен ~10 дней), не
Метрика. Это даже точнее: клики по ссылке в TG/VK не режутся адблокерами/ITP,
как может резаться JS-трекер Метрики. Ретеншен логов короче окна анализа →
сбор строго инкрементальный (по последнему `measuredAt` снимка, `measuredAt`
нового снимка = максимальный timestamp обработанного клика, не `now()` —
идемпотентно при повторных прогонах и не зависит от расхождения часов Mac/прод).
`CaptionGenerator::withUtm` теперь добавляет `utm_content=p<id>` — точная
атрибуция клика к посту; fallback без него — платформа+рубрика+окно публикации
(14 дней). `SocialEvaluateCommand` и сущность метрик получают данные, крон —
`30 7 * * *` на Mac. Платформенные saves/shares — отдельным инжестером позже.

### Фаза 1 — save-утилиты для покупателя (данные готовы) — ✅ сделано 2026-07-13
1. **«Чем заменить ушедших»** — рубрика `replace_departed` (пт), source `departed`
   (`DepartedCaptionSource`): читает `config/social/departed_brands.yaml`, курсор ротации =
   `countByRubric()` % число записей (зеркало `brandCursor` в `SocialPlanner`). Тело
   двухслойное: LLM-лид строго на фактах записи (departed/niche/successor/successor_note)
   + детерминированная строка «Российские альтернативы: …» (НЕ LLM, имена по slug только
   `status=active`; запись с <2 живыми alt пропускается, берётся следующая по курсору).
2. **Demand-рубрика из `brand_keyword`** — рубрика `demand` (вт), source `demand`
   (`DemandCaptionSource`): топ-фраза бренда (`BrandKeywordRepository::findTopByBrand`,
   ORDER BY monthlyShows DESC) → пост-ответ на реальный спрос, факты — из описания бренда.
   Нет ключевиков у бренда → фолбэк на `BrandDescriptionCaptionSource`.
3. **brand_week → история основателя** — source рубрики `brand_week` сменён на
   `founder_story` (`FounderStoryCaptionSource`): нарратив из RAG-фактов `BrandRagService`
   (gate качества chunks≥3 И score≥0.5 уже внутри сервиса). Gate не пройден/Qdrant
   недоступен (IP непостоянен) → фолбэк на `BrandDescriptionCaptionSource`.

Слот/needsBrand/media рубрик не менялись — только source. `calculator`/`vs_marketplace`
остаются в `SocialRubrics::CATALOG` (day=0, вне еженедельной сетки) как backing-def для
`SocialPlanner::AUTO_FALLBACK`. Тесты — `tests/Service/Social/Source/*Test.php`.

### Фаза 2 — дешёвый постоянный контент
4. **Тизеры блога/энциклопедии** — уже опубликованный (уже QA-нутый) лонгформ →
   тизер со ссылкой. Почти нулевой риск, компаундится с Дзен-автопилотом.
5. **Дайджест каталога из SignalCollector** — «за неделю +N брендов, растёт
   категория X»; самообновляемый discovery-контент без выдумок.

### Фаза 3 — развести аудитории: founder-канал
6. Отдельный TG-канал основателям: туда переезжают calculator/manifesto/
   vs_marketplace + новая рубрика **founder_playbook** — кросс-опыление
   `AdvisorRag` (роли idea/framing/case) × `brand_chunks`: бизнес-принцип,
   приложенный к реальному кейсу бренда из каталога, CTA — подписка 0%.
   Это легитимная площадка для YouTube-базы и продажа подписки без шума
   в консюмерском фиде.
