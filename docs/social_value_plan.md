# Ценность в соцсетях: синтез двух независимых анализов (2026-07-10)

Метод: два независимых deep-reasoner-прогона (рамка «аудитория/ценность» и рамка
«системная: данные→контент»), без взаимного доступа, затем синтез. Входные разведки:
конвейер соц-постов (`src/Service/Social/`, `docs/marketing_instagram.md`) и
YouTube-обогащение RAG (`topic_chunks`, 715 транскриптов 5 бизнес-каналов, юзается
только советником).

## Диагноз (сошлись обе рамки)

1. **Closed-loop разомкнут** — метрики не собираются, KPI (saves·3+shares·3+linkTaps·2)
   не на чем проверять. Любая новая рубрика без этого — ставка вслепую.
2. **~43% сетки — B2B-самопиар в консюмерском фиде** (вт calculator, чт manifesto,
   пт vs_marketplace): покупателю безразличны комиссии WB/Ozon, а основатель бренда
   консюмерский канал не читает. Это и есть «рекламный шум».
3. **Нет ни одной save-утилиты** («где купить X», «чем заменить ушедших») — то,
   ради чего фэшн-контент вообще сохраняют и пересылают.
4. `brand_week` — LLM-подпись из описания = дженерик без крючка.

## Правило безопасности для YouTube-базы (ключевое, снимает 3 риска разом)

**topic_chunks → только framing/angle, никогда → факты.** Жёсткие утверждения
(цифры, факты) — только из PILLARS и `brand_chunks`. Публикуем оригинальный
парафраз голосом WEARBASE, никогда не verbatim-текст транскрипта;
`rag_citations` — внутренний провенанс, спикеров публично не называем
(нет имплицитного эндорсмента); исключение — явная отсылка к именной методологии
с честной атрибуцией. Это одновременно нейтрализует: копирайт (охраняется
выражение, не идеи), ошибки авто-субтитров (yt-dlp, не whisper!), галлюцинации.

## Роадмап (ранжирован по ценность × реалистичность)

### Фаза 0 — замкнуть петлю (enabler)
UTM-клик-инжестер: `CaptionGenerator::withUtm` уже шьёт `utm_source/campaign` —
команда, читающая Метрику (или парсящая логи; **выяснить: есть ли API-доступ
Метрики** — это определяет трудоёмкость) → `social_post_metric.link_taps`.
`SocialEvaluateCommand` и сущность метрик уже готовы. Платформенные saves/shares —
отдельным инжестером позже.

### Фаза 1 — save-утилиты для покупателя (данные готовы)
1. **«Чем заменить ушедших»** — rebrand-данные (MAAG≈Zara, Ростикс) + каталог.
   Максимальный интент и пересылаемость; связка с гипотезой rebrand-интента
   (memory: wearbase-rebrand-intent).
2. **Demand-рубрика из `brand_keyword`** — топ-фраза Wordstat → пост-ответ на
   реальный спрос, факты из `brand_chunks`. Двойная польза: соцсети + GEO/SEO.
3. **brand_week → история основателя** — тот же слот, но нарратив из RAG-фактов
   (почему начал, город, путь), а не пересказ описания.

### Фаза 2 — дешёвый постоянный контент
4. **Тизеры блога/энциклопедии** — уже опубликованный (уже QA-нутый) лонгформ →
   тизер со ссылкой. Почти нулевой риск, компаундится с Дзен-автопилотом.
5. **Дайджест каталога из SignalCollector** — «за неделю +N брендов, растёт
   категория X»; самообновляемый discovery-контент без выдумок.

### Фаза 3 — развести аудитории: founder-канал
6. Отдельный TG-канал основателям: туда переезжают calculator/manifesto/
   vs_marketplace + новая рубрика **founder_playbook** — кросс-опыление
   `AdvisorRag` (роли idea/framing/case) × `brand_chunks`: бизнес-принцип,
   приложенный к реальному кейсу бренда из каталога, CTA — подписка 0%.
   Это легитимная площадка для YouTube-базы и продажа подписки без шума
   в консюмерском фиде.

## Техника

- Источников контента станет 2 → ~6: единственный оправданный рефакторинг —
  выделить `CaptionSourceInterface` (strategy, tagged services), чтобы
  `CaptionGenerator` не рос жирным switch'ем. Паттерн расширения единый:
  запись в `SocialRubrics::CATALOG` + source-builder.
- GPU: соц-объёмы мизерны; generate гонять вне пиков, не параллелить с
  RAG/keyword-батчами (крон-диспетчер уже сериализует).
- VK постит только текст (photos.* TODO, `VkPublisher.php:15`) — визуальная
  ценность Фаз 1–2 на VK ограничена, поднять приоритет TODO.
- IG даунранкает внешние ссылки — link-CTA-рубрики роутить в TG/VK.
- Анти-спам: гейт на near-duplicate подписей перед публикацией; рамп +12.5%/нед
  уже ограничивает объём.
