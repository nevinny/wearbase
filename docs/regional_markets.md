# Региональные рынки: стратегия экспансии

> Решение от 2026-07-05. Синтез двух независимых анализов (GTM/SEO и продукт/техника/риски).
> Гипотеза пользователя: модель «каталог локальных брендов страны X» универсальна (пример: каталог немецких локальных брендов).

## Вердикт

**Полноценный второй рынок сейчас НЕ открывать. Вместо этого — почти бесплатная разведывательная
SEO-витрина на EU-хостинге из уже запаркованного foreign-контента + две подготовки, полезные и для RU.**
RU-дрип только разогнался (Яндекс ×2, pages-in-search 339→494) — разбавлять фокус дорого, а настоящие
блокеры экспансии не технические: платёжка и outreach.

## Ключевые выводы

### Спрос и выбор рынка (GTM-анализ)
- Сильнейший локальный интент — **Франция**: «made in France» — оформленное потребительское движение
  (Le Slip Français, France Terre Textile; запросы «marques françaises», «vêtements made in France»).
  Германия — интент про устойчивость («faire Mode»), размытее и конкурентнее. Италия — «made in Italy»
  глобальный люкс-ярлык, локального discover-интента мало. TR/PL — хуже качество gemma + покупательная
  способность. UK — дорогой SERP.
- SERP-щель есть: доминирующего агрегатора местных брендов нет нигде, NJAL слаб в локальном SEO —
  та же щель, где сработала RU-модель.
- **Seed-корпус (замер 2026-07-05, по country-полю)**: Италия 66 брендов (46 с готовым контентом),
  США 33/17, Франция 25/10, Германия 22/15. После ретро-батча origin-check цифры уточнить —
  country заполнен лишь у ~8%.

### Блокеры монетизации (риск-анализ)
- **Платёжка — блокер №1**: YooKassa вне РФ не работает; Stripe для РФ-резидента недоступен;
  Paddle/LemonSqueezy (MoR) требуют KYC — фактически нужно нерезидентное юрлицо/счёт.
- **Cold outreach в DE юридически токсичен**: UWG §7 требует предварительного согласия на B2B-email —
  claim-воронка «письмо владельцу» не переносится. GDPR legitimate interest для холодных писем шаткий.
- Impressum/cookie-consent — решаемо шаблоном; блокер только при коммерции.
- Вывод: региональный каталог на 12 мес — **SEO-актив (трафик/affiliate), не subscription-бизнес**.

### Архитектура (на 3–5 стран, соло-оператор)
- Мультитенант в монолите — ломается на юрисдикциях (GDPR vs ЗоЗПП, платёжки, hreflang, РФ-хостинг).
- N полных инстансов — N деплоев/кронов, смертельно соло уже на 3.
- **Целевое: seo-factory (общий конвейер, одна ollama) + тонкие фронты на своих доменах/EU-хостингах.**
  Совпадает с уже существующим планом выноса конвейера.
- Замены в конвейере для не-RU: discover — DataForSEO SERP / Brave Search API; **ключевики — из Google
  (решение пользователя 2026-07-05)**; trafilatura/embed/generate — язык-агностичны, gemma4 на FR/DE
  достаточна. В `KeywordService` при выносе в seo-factory закладывать интерфейс источника
  (драйверы Wordstat | Google).

### Источник Google-ключевиков (ресёрч 2026-07-05)

- **Батч-конвейер: DataForSEO** — Keywords Data API «Google Ads search volume» (до 1000 ключевиков
  за задачу, $0.06 standard queue → **~$6/100k точных объёмов**, не диапазонов) + Labs keyword ideas
  (~$0.13/1000 идей) ≈ **$20/мес на 100k**. Депозит $50, pay-as-you-go. FR=location 2250, DE=2276.
  Ложится в паттерн `WordstatClient` (батчи + статус-поле). ⚠️ Оплата только зарубежной картой
  (Visa/MC РФ не работают, компания эстонско-украинская) — тот же биллинг-блокер, что и MoR.
- **Разовая валидация**: Google Keyword Planner UI бесплатно (диапазонов хватит для sanity-check)
  или Keywords Everywhere ($84/год, данные того же Keyword Planner).
- **Google Ads API напрямую** — только если появится тратящий Ads-аккаунт: без расхода ~$50–100+
  отдаёт диапазоны 1K–10K, а не точные объёмы; нужен MCC + developer token (модерация Basic access);
  Ads в РФ приостановлен → аккаунт/биллинг только на нерезидента.
- **Бесплатное дополнение**: Google Autocomplete (`suggestqueries.google.com`, hl/gl=fr) — расширение
  «brand + модификатор» без объёмов, троттлинг ~1–2 rps. Trends API (alpha) — не для конвейера.
- Serpstat (не обслуживает РФ) и SE Ranking (API от ~$239/мес) — не брать.
- Отдельный чистый ccTLD без связи с wearbase.ru (российский след убивает доверие и claim);
  перелинковку и hreflang с wearbase.ru не делать.

## План (последовательность)

1. **Пре-валидация без стройки (дни, ~0₽)**: Keyword Planner/DataForSEO по 30–40 FR-фразам
   («marques françaises [catégorie]», «créateurs mode française»); порог интереса — суммарно 20k+/мес
   по мид-тейлу. Спарсить топ-10 по 15 запросам: если верх — блоги/подборки, а не агрегатор → щель есть.
2. **Разведвитрина (недели, €5–20/мес)**: свежий домен (.fr при подтверждении спроса), Hetzner (DE),
   30–50 страниц из foreign-корпуса (FR-приоритет; добор discover'ом), только каталог+листиклы, один язык,
   **без outreach, без платёжки, без сбора новых перс.данных** (= минимум GDPR/Impressum). IndexNow + GSC.
3. **Подготовка, полезная и RU (параллельно)**: вынос конвейера в seo-factory; абстракция
   keyword-источника (интерфейс над Wordstat → драйверы GKP/DataForSEO).
4. **Монетизацию DE/FR не проектировать**, пока не выполнены все go-условия ниже.

## Валидация спроса FR vs DE (2026-07-05, бесплатные каналы)

Методика: Google Autocomplete (40 seed-фраз/страну + alphabet-расширение, hl/gl целевой страны;
сырьё в scratchpad `fr|de_autocomplete_results.json`) + SERP-разведка ~12 запросов/страну
(WebSearch/WebFetch) + разбор конкурентов. Точные объёмы НЕ измерены (нужен GKP UI / DataForSEO).

### Франция — спрос богаче, щель шире

- Autocomplete: **35/40 фраз живые, 316 уникальных подсказок**; каталожный интент прямо в подсказках
  («liste marque française vêtement femme/homme/streetwear», «top 100 marques françaises vêtements»,
  «annuaire»). Femme — сильнейший сегмент (29 вариаций); éthique/durable подтверждён; у chaussures
  гео-паттерн (paris/nantes/romans) — под будущие город-страницы.
- SERP: доминирующего агрегатора нет, generic-топы у слабых блогов-листиклов. Конкуренты:
  **marques-de-france.fr** (1178 брендов, зрелый, но карточки тонкие и мода размыта «всем made in France»),
  lesmarquesfrancaises.fr (670, «лого+теги»), lesitedumadeinfrance.fr (product-feed, уязвим к HCU).
  Полностью открыты: streetwear, jeunes créateurs, города/регионы.
- Спрос-прокси: 85% французов покупают MIF (independant.io), рынок MIF-одежды >7 млрд €;
  Primelis (1200 ключевиков): ВЧ мало, трафик в длинном хвосте — совместимо с нашей моделью.
- ⚠️ **Прецедент La Saperie Française**: каталог на 320 брендов умер в 10.2022 при попытке перевести
  бренды с бесплатного листинга на платную подписку → подтверждает «SEO-актив/affiliate, не subscription».

### Германия — щель есть, но спрос беднее и fair-ниша занята

- Autocomplete: 32/40 фраз, **110 уникальных подсказок (вдвое беднее FR)**; каталожный интент есть,
  но сконцентрирован вокруг одного ядра «deutsche modemarken» (28 alphabet-подсказок:
  beste/top/größte/erfolgreichste/liste…), по остальным темам тонко. Damen/herren — сквозной сигнал,
  nachhaltig — второй по силе; продуктовые «made in germany»-запросы (schuhe/jeans) тянут
  брендово-товарный хвост, не списки. Соседняя богатая ниша — deutsche uhrenmarken.
- SERP: доминирующего каталога нет (щель как в RU), но **nachhaltig/fair-кластер насыщен**
  (Utopia Bestenliste — авторитетный домен, Avocadostore — маркетплейс 7k марок, гос-знак Grüner Knopf) —
  лоб-в-лоб не входить. Недообслужены: generic «deutsche modemarken», города, streetwear,
  made-in-germany по вертикалям. getchanged.net мёртв, Fashion Changers — 45 брендов-активистов.

**Чтение**: у Франции три головных ключа 1–10 тыс./мес (продуктовые «made in france»), у Германии
головных нет вообще — потолок 100–1 тыс. Сумма по 20-фразовой пробе: FR ≈ 4–35 тыс./мес,
DE ≈ 1–7 тыс./мес — Франция ×3–5 ёмче на сопоставимой пробе. Проба — малая часть кластера
(Primelis: 1200 ключевиков темы) → **порог 20k+/мес для FR реалистичен по полному кластеру;
для DE — сомнителен**. Продуктовые MIF-запросы (обувь/джинсы/футболки) — самые ёмкие → в MVP
нужны категорийные листиклы «chaussures made in France», не только бренд-каталог.

### Вердикт валидации

**Гипотеза «модель реплицируема» подтверждена для обеих стран; Франция первая** (спрос ~×2 богаче,
каталожный интент выражен, культурный драйвер «made in France» сильнее, конкуренты слабы в нашем
формате контентных бренд-карточек). Германия — кандидат №2, входить через недообслуженные кластеры
(generic/города/streetwear), не через fair. Ограничение: численный порог 20k+/мес не проверен —
финализировать 10-минутным заходом в Keyword Planner UI (диапазоны) до покупки домена.
Seed-контент RU-корпуса по FR/DE-брендам — **на русском**: переиспользуются факты/корпус, но генерация
страниц нужна заново на целевом языке (дёшево, ollama).

## Go / No-go / Kill

- **Go на полноценный рынок №2** — только все три одновременно:
  (а) RU claim→subscription доказан первыми платящими; (б) RU-дрип на автопилоте без еженедельного
  ручного вмешательства; (в) разведвитрина показала органику (2–3 страницы в топ-20 по мид-тейлу
  без бэклинков, рост non-branded impressions за 4–6 недель).
- **Kill разведвитрины**: 6 мес без индексации/органики → foreign-рынок мёртв, часы назад в RU.
- **Kill по монетизации**: нет платящих подписок в РФ → рынок №2 закрыт по определению.
- Стоимость полноценного 2-го рынка (для справки): +8–12 ч/нед первые 2–3 мес, юрист/Impressum €200–500,
  MoR-комиссия — сейчас плохой обмен против растущего RU.
