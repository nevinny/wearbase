# Ссылки из Instagram: что работает (разведка 07.10.2026)

Ссылки в подписи и в комментариях IG не кликабельны. Первый комментарий со ссылкой убран из `InstagramPublisher` 07.10.2026: механика не работала.

| Способ | Кликабельно | Нам доступно | Автоматизация |
|---|---|---|---|
| Ссылка в био (до 5) | да | 1 ссылка точно; 3–5 — по источникам, у части аккаунтов с Meta Verified | вручную |
| Ссылки в подписях Reels | да | только Meta Verified (тест, лимит ~10/мес) | — |
| Стикер «Ссылка» в Stories | да | всем, без порога подписчиков | Graph API стикер не поддерживает → вручную |
| Комментарий с кодовым словом → ответ в директ со ссылкой | да | да | Instagram Messaging / Private Replies. ManyChat требует FB-страницу. Для нашего Instagram Login проверить, нужна ли она, — не подтверждено |
| Своя link-in-bio страница на wearbase.ru с UTM | да | да | да |

Рекомендации по порядку:
1. Своя страница в био (`wearbase.ru/ru/ig` или аналог) с UTM и 3–5 крупными кнопками. CTA в роликах — «ссылка в профиле».
2. Кодовое слово в комментарии → автоответ в директ со ссылкой (Private Replies). Сначала проверить скоупы `instagram_business_manage_messages` / `manage_comments` у нашего токена Instagram Login.
3. Stories со стикером-ссылкой вручную для ключевых роликов.

Источники: soci.ai (link in bio, 2026), planoly (тест ссылок в подписях), shareb.io (требования к стикеру 2026), manychat.com, developers.facebook.com (Instagram Messaging API).
