# Цена ручной работы: одна grounded-карточка руками против конвейера

Расчёт под win-win-оффер пути B («твои N часов ручной работы → столько-то ₽/мес и минуты»),
методика — из [разбора 542 стартапов YC-2026](romarayt_ai_product_models_2026.md).
Считано 2026-08-05 по dev-БД Mac и логам конвейера. Порядок изложения важен:
сначала **измеренное**, потом **допущения**, потом вывод — чтобы цифру можно было защитить в разговоре
с клиентом и пересчитать при споре о нормах.

## 1. Что конвейер реально делает на один бренд (измерено)

Медианы по **3479** брендам с успешно завершённой генерацией (`brand_rag_pipeline.status='done'`;
из них опубликовано 1242). Медиана, а не среднее — хвосты кривые.

| Величина | Медиана | Откуда |
|---|---|---|
| URL скачано и отфильтровано | 31 | `brand_source_url` (status=fetched) |
| документов легло в корпус | 13 | `brand_source_document` (embedded=1) |
| **символов исходника прочитано** | **26 004** | `brand_source_document.char_count`, embedded=1 |
| символов на выходе (description) | 2 527 | `brand.description` |
| + meta_title / meta_description / meta_keywords | 41 / 137 / 111 | `brand.*` |
| + анонс (есть у 1534 из 3479) | 271 | `brand.anons` |
| **итого готового текста** | **2 880** | сумма пяти полей |
| FAQ-вопросов | 4 | `brand_faq` |
| заполненных атрибутов | 16 | `brand_attribute` |
| ключевиков с частотностью | 11 | `brand_keyword` |

Корпус целиком: 191 492 точки в `brand_chunks` (чанк 1500 симв, перекрытие 240 —
`src/Service/TextChunker.php:11-12`; медиана длины чанка по выборке 1499).

## 2. Сколько это стоит руками (реконструкция)

Объёмы взяты из §1, **нормы выработки — допущения** (помечены явно; измерить их у нас нечем,
своего редактора на этой работе не было).

| Этап ручной работы | Норма (допущение) | Минут |
|---|---|---|
| Поиск и фильтрация 31 кандидата (открыть, оценить, отбросить шум: вакансии, чужие домены) | 1–2 мин/URL | 31–62 |
| Чтение 26 000 симв ≈ 4 060 слов с выпиской фактов | 180 / 90 слов-мин | 23–45 |
| Написание 2 880 симв фактурного текста + мета | 2500 / 1500 симв-час | 69–115 |
| 4 FAQ с обоснованными ответами | 5–7 мин/вопрос | 20–28 |
| 16 атрибутов с проверкой | 1,5–2 мин | 24–32 |
| 11 ключевиков (Wordstat руками) | 1,5 мин | 16 |
| **Итого** | | **183–299 мин = 3,1–5,0 ч** |

В деньгах: **1 530–2 490 ₽** при 500 ₽/ч, **2 440–3 990 ₽** при 800 ₽/ч (редактор-ресёрчер, фриланс).

**Внешняя проверка по рынку РФ, 2026** (цена за 1000 знаков готового текста; наши 2 880 знаков):
средний уровень 300–500 ₽ → 860–1 440 ₽; опытный фрилансер 700–2000 ₽ → 2 000–5 760 ₽;
агентство (SEO-статья) 3000–5000 ₽ → 8 640–14 400 ₽ ([Kadrof](https://www.kadrof.ru/articles/5343),
[Workspace](https://workspace.ru/blog/skolko-stoyat-teksty-polnyy-rasklad-po-rascenkam/),
[prpanda](https://prpanda.ru/stoimost-stati-na-zakaz-vo-skolko-obojdutsya-uslugi-avtorov-v-2026-godu/)).
Наша оценка снизу-вверх (1 530–2 490 ₽) попадает в фрилансерский диапазон, **при том что цена за знак
не покрывает ресёрч, FAQ, атрибуты и ключевики** — то есть оценка консервативна, а не завышена.

## 3. Себестоимость конвейера на бренд (измерено по коду)

| Статья | ₽/бренд | Откуда |
|---|---|---|
| Yandex Search API (discover) | ≤ 4,41 | 0,49 ₽/запрос (`src/Service/YandexSearchMeter.php:21`) × ≤9 запросов (T1 1 + T2 4–5 + T3 3, `BrandSourceFinder::discoverTiered`) |
| Wordstat (ключевики) | 0 | 1 запрос/бренд, квота 100/ч (`Keyword/WordstatClient.php`) |
| Скрейп, эмбеддинг, генерация, FAQ | ≈ 0 | свой 4-GPU сервер, только электричество ([monetization_economics.md:22](monetization_economics.md)) |
| Brave (fallback-добор) | 0 | 1000/мес бесплатно |

Итого маржинальная себестоимость — **≤ 4,4 ₽ на карточку**, и это уточнение прежнего «≈0 ₽»
([proof_pack.md:38](proof_pack.md)), а не противоречие ему.

**Машинное время:** активное — минуты. Якорь из `var/log/rag-daemon.log`: один цикл демона 15 мин 12 с
дотянул 67 брендов до `scraped`, заэмбеддил 30 (611 чанков) и сгенерировал 8 карточек — этапы идут
пакетно и параллельно. ⚠️ Медианы по таймстампам БД (discover→generate 2 925 мин) использовать нельзя:
это задержка асинхронной крон-очереди, а не обработка; вдобавок у 13,9% строк дельта embed→generate
отрицательная из-за regen-циклов.

## 4. Вывод для оффера

- **На одну карточку: 3,1–5,0 человеко-часа против ≤4,4 ₽ и минут машинного времени.**
  Разрыв в деньгах — **350–570×** против фриланса (500 ₽/ч) и **65–130×** даже против самой дешёвой
  биржевой ставки (100–200 ₽/1000 знаков).
- **Накопленное:** 3479 готовых карточек = **10 600–17 300 человеко-часов = 6,2–10,2 человеко-года**
  ручной работы, или **5,3–13,9 млн ₽** (500–800 ₽/ч). Только по опубликованным (1242) —
  3 800–6 200 ч ≈ 2,3–3,7 млн ₽ при 600 ₽/ч. Это же и ответ на «жёсткий фильтр 20 пар вход→выход»
  из методики: у нас их 3479, с сохранёнными источниками.
- **Формула win-win для владельца каталога на 500 брендов:** руками 1 550–2 500 ч ≈ 0,8–2,0 млн ₽ и
  год работы редактора → подписка 30–50 тыс ₽/мес окупается в первый месяц. Альтернативный якорь —
  300–500 ₽ за карточку: в 5–8 раз дешевле фрилансера по совокупности работ и в 20–30 раз дешевле
  агентства, при нашей себестоимости ≤4,4 ₽.
- Продаём при этом **контрольный слой** (гейт качества, ниша-гейт, аудит источников, ролбек), а не
  «AI-генерацию» — см. [разбор](romarayt_ai_product_models_2026.md), рынок контроля = 9,4% выборки YC.

## 5. Что в расчёт НЕ входит

- **Размещение и модерация** готового результата — отдельные 1–2 ч/бренд, уже зафиксированы в
  [monetization_economics.md:66-68](monetization_economics.md) (разовая услуга 5000 ₽/бренд). Наши
  3,1–5,0 ч — это ресёрч + текст + артефакты, то есть **другая часть работы**, они складываются, а не
  конкурируют.
- Правки после гейта, лого/фото, съёмка, юридическая проверка.
- Тарифы Basic 1500 ₽/мес и Premium 3000 ₽/мес из monetization_economics.md — это подписка **брендов**
  в каталоге, другой продукт; не путать с ценой услуги для владельца внешнего каталога.
- Нормы чтения (180/90 слов-мин) и письма (2500/1500 симв-час) — допущения. Объёмы измерены, нормы нет:
  при споре пересчитывать таблицу §2, измеренные величины §1 не меняются.
