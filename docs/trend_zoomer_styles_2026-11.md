Сырьё для нового хаба тонкое. В свободном тексте `brand_attribute(name=style)` значение «indie sleaze» стоит
**у одного бренда**. Близких значений около 30: rock / рок-н-ролл / western / панк / rock-chic / goth rock / hip-hop / рэп-эстетика.
Если завести хаб только по словарю синонимов, он выйдет пустым. Нужен LLM-проход, который заново разметит
бренды с чёрной кожей, клёшами и ковбойскими сапогами.

## 4. Что из этого применить у нас (по порядку)

1. **Описание для хаба `/ru/style/y2k`** (183 бренда, описание пустое). Хаб уже существует, а рилс подтверждает, что
   термин живой. Делается одной командой: `app:seo:style-hub --style=y2k`. Риска нет.
2. **Новый стиль `indie-sleaze` («Индислиз»)**: спрос около 10К в месяц, хаба у нас нет. Что нужно:
   - добавить в `CANON` и `SYN` в `TagBrandStylesCommand` синонимы: индислиз, indie sleaze, инди слиз, рок-шик;
   - заново разметить бренды через LLM по признакам «чёрная кожа, клёш, казаки, рок» и вручную проверить,
     наберётся ли хотя бы ~15 брендов;
   - сгенерировать текст хаба через `app:seo:style-hub`.
   Определение для текста хаба берём у самих зумеров: «казаки + кожанка + чёрные клёши».
3. **Новый стиль `drip` или подборка «Дрип без палёнки: российские бренды»** закрывает «дрип одежда» (8К),
   «дрип бренды одежды» и «российский стритвир бренды». Ключевой аргумент — сам ролик: «главное — бренд, может быть
   палёным». Мы показываем настоящие локальные бренды вместо поддельных Amiri и BAPE. Важно: заходить через стиль,
   а не через сравнение с Amiri и BAPE по названию. Чужие марки в SEO-заголовках — юридический риск.
4. **Тексты и подписи.** «Ниша» и «нишевый» для этой аудитории — похвала. Это готовые слова для H1, подписей и
   сторис: «нишевые российские бренды», «пока за них никто не прошарил».
5. **Соцсети.** Для рубрики брендов — серия «одна вещь в стиле»: казаки, кожанка, чёрные клёши (индислиз).
   Брать только из фото наших брендов, по существующему конвейеру Reels.

Пункты 2 и 3 меняют публичный каталог и уходят на прод через PR. По tasktracker действует заморозка WIP=1 до
первой продажи, поэтому решение — за владельцем.
