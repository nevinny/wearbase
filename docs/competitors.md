# Конкуренты WEARBASE

> Разбор конкурентов для SEO/продукта. Ревизия: 2026-06-14.

## vitrine.market

Прямой конкурент: каталог российских брендов одежды. **Транзакционный маркетплейс с
комиссией** (бенчмарк ниши 30–67%), эскроу (деньги бренду после получения заказа),
iOS+Android-приложения, чат покупатель↔бренд, дропы/предзаказы, отзывы, промокоды.
ИП Свольский, запуск июль 2025. **276 брендов + ~4100 товаров** в sitemap. Технически —
SPA с server-side рендером head/JSON-LD для краулеров.

### Что у них сильнее (перенять)
1. **`Product`+`Offer` JSON-LD** (price/priceCurrency/availability/seller/sku/brand) +
   **5-уровневый `BreadcrumbList`** на товаре → eligible для shopping/rich-результатов.
2. **Транзакционные шаблонные title:** «Купить {категория} от {бренд} — {цена} ₽».
3. **Цифры соц-доказательства в карточке и meta:** год основания, город, «30 000 продаж ·
   5 000 отзывов» → в сниппет Google, бустит CTR.
4. **`/releases`** — лента дропов/новинок: свежий индексируемый контент.
5. **Стилевые «вселенные»** (streetwear/opium/gorpcore/Y2K/archive) как фасет/хабы → лонгтейл.
6. Богатые фасеты (стиль/материал/цвет/пол), `/map` гео, эталонно чистый robots.txt
   (закрыт весь транзакционно-персональный слой: `/cart /favorites /orders /chats /account
   /search /api*`).

### Где они слабы (наш козырь)
- Карточки брендов: **title = голое имя бренда**, description у ВСЕХ одинаковый «Страница
  бренда»; у товаров **meta description нет вообще**. Контент UGC-тонкий, без FAQ/фактов/
  истории/перелинковки карточка↔карточка и карточка↔гео-хаб.
- **Нет hreflang/мультиязычности** (`ru_RU` хардкод, только РФ) — структурно не могут в
  международную выдачу. Наш `/{_locale}/`+hreflang+translation-стек — моат.
- Слаги — сырые имена брендов (`/brand/corpse+farm`, кириллица, пробелы, точки) → дубли/
  проблемы канонизации. Наша слагификация лучше.
- SPA со слабым SEO-слоем; редакционного/RAG-контента нет — наша зона силы.

### Наши преимущества (давить)
- **0% комиссии с продаж, деньги напрямую бренду** (vs их 30–67% + эскроу) — сильнейший
  крючок для привлечения брендов. Громко коммуницировать.
- hreflang/мультиязычность · чистые слаги · city-хабы · RAG-энциклопедия брендов.

### Продуктовый разрыв (не SEO; если идём за покупателя)
Приложения iOS/Android · чат с брендом · дропы/предзаказы · отзывы/рейтинги · промокоды.

### Приоритетные SEO-действия для wearbase (по отдаче)
1. `Product`+`Offer` JSON-LD + `BreadcrumbList` на карточках товара/бренда (rich-результаты).
2. Фактоид-блок + `meta_description` из RAG: «основан {год} · {город} · {факты}» вверху
   карточки и в мете (бьёт по их generic «Страница бренда»).
3. Транзакционные title («Купить … от … — ₽» / «{бренд} — российский бренд {категория}, купить»).
4. Стилевые хабы `/style/{slug}` — новый класс лонгтейла (лексикон их, но SEO слабый — окно открыто).
5. Лента `/releases` (новизна брендов/товаров) — индексируемый поток для краула.
6. Гигиена robots: свериться, что транзакционный/ЛК-слой закрыт.

### Lead-gen: бренды vitrine — цель нашего маркетинга/продаж
Бренды, размещающие товар у vitrine (комиссия 30–67%), — прямая цель оффера wearbase
«0% комиссии, деньги напрямую». Сверка их `sitemap-brands.xml` (276) с нашей БД (2026-06-14):
- **13** уже у нас (9 без enriched-контакта → цель обогащения);
- **263 новых** (нет в нашей БД) → чистые лиды. Список имён: `var/vitrine-leads.txt`.

Воронка: имена → завести как `brand` (status new) → `app:brand:enrich-contacts` (perplexity:
сайт/email) → `app:outreach:send` с питчем «0% vs 30–67%». ⚠️ WAF vitrine банит по IP при
частых запросах — sitemap тащить редко и/или с прод-IP (`ssh regru curl …`), не с Mac пачкой.

Источники: vitrine.market, /brands, /sitemap*.xml, robots.txt, t.me/s/vitrine_market.
