# Конкуренты WEARBASE

> Разбор конкурентов для SEO/продукта. Ревизия: 2026-06-14.

## vitrine.market

Прямой конкурент: каталог российских брендов одежды. **Транзакционный маркетплейс с
комиссией** (бенчмарк ниши 30–67%), эскроу (деньги бренду после получения заказа),
iOS+Android-приложения, чат покупатель↔бренд, дропы/предзаказы, отзывы, промокоды.
ИП Свольский, запуск июль 2025. **276 брендов + ~4100 товаров** в sitemap. Технически —
SPA с server-side рендером head/JSON-LD для краулеров.

### Что у них сильнее (перенять)
1. **`Product`+`Offer` JSON-LD** (price/priceCurrency/availability/seller/sku/brand) +
   **5-уровневый `BreadcrumbList`** на товаре → eligible для shopping/rich-результатов.
2. **Транзакционные шаблонные title:** «Купить {категория} от {бренд} — {цена} ₽».
3. **Цифры соц-доказательства в карточке и meta:** год основания, город, «30 000 продаж ·
   5 000 отзывов» → в сниппет Google, бустит CTR.
4. **`/releases`** — лента дропов/новинок: свежий индексируемый контент.
5. **Стилевые «вселенные»** (streetwear/opium/gorpcore/Y2K/archive) как фасет/хабы → лонгтейл.
6. Богатые фасеты (стиль/материал/цвет/пол), `/map` гео, эталонно чистый robots.txt
   (закрыт весь транзакционно-персональный слой: `/cart /favorites /orders /chats /account
   /search /api*`).

### Где они слабы (наш козырь)
- Карточки брендов: **title = голое имя бренда**, description у ВСЕХ одинаковый «Страница
  бренда»; у товаров **meta description нет вообще**. Контент UGC-тонкий, без FAQ/фактов/
  истории/перелинковки карточка↔карточка и карточка↔гео-хаб.
- **Нет hreflang/мультиязычности** (`ru_RU` хардкод, только РФ) — структурно не могут в
  международную выдачу. Наш `/{_locale}/`+hreflang+translation-стек — моат.
- Слаги — сырые имена брендов (`/brand/corpse+farm`, кириллица, пробелы, точки) → дубли/
  проблемы канонизации. Наша слагификация лучше.
- SPA со слабым SEO-слоем; редакционного/RAG-контента нет — наша зона силы.

### Наши преимущества (давить)
- **0% комиссии с продаж, деньги напрямую бренду** (vs их 30–67% + эскроу) — сильнейший
  крючок для привлечения брендов. Громко коммуницировать.
- hreflang/мультиязычность · чистые слаги · city-хабы · RAG-энциклопедия брендов.

### Продуктовый разрыв (не SEO; если идём за покупателя)
Приложения iOS/Android · чат с брендом · дропы/предзаказы · отзывы/рейтинги · промокоды.

### Приоритетные SEO-действия для wearbase (по отдаче)
1. `Product`+`Offer` JSON-LD + `BreadcrumbList` на карточках товара/бренда (rich-результаты).
2. Фактоид-блок + `meta_description` из RAG: «основан {год} · {город} · {факты}» вверху
   карточки и в мете (бьёт по их generic «Страница бренда»).
3. Транзакционные title («Купить … от … — ₽» / «{бренд} — российский бренд {категория}, купить»).
4. Стилевые хабы `/style/{slug}` — новый класс лонгтейла (лексикон их, но SEO слабый — окно открыто).
5. Лента `/releases` (новизна брендов/товаров) — индексируемый поток для краула.
6. Гигиена robots: свериться, что транзакционный/ЛК-слой закрыт.

### Lead-gen: бренды vitrine — цель нашего маркетинга/продаж
Бренды, размещающие товар у vitrine (комиссия 30–67%), — прямая цель оффера wearbase
«0% комиссии, деньги напрямую». Сверка их `sitemap-brands.xml` (276) с нашей БД (2026-06-14):
- **13** уже у нас (9 без enriched-контакта → цель обогащения);
- **263 новых** (нет в нашей БД) → чистые лиды. Список имён: `var/vitrine-leads.txt`.

Воронка: имена → завести как `brand` (status new) → `app:brand:enrich-contacts` (perplexity:
сайт/email) → `app:outreach:send` с питчем «0% vs 30–67%». ⚠️ WAF vitrine банит по IP при
частых запросах — sitemap тащить редко и/или с прод-IP (`ssh regru curl …`), не с Mac пачкой.

Источники: vitrine.market, /brands, /sitemap*.xml, robots.txt, t.me/s/vitrine_market.

## brandshop.ru

**НЕ конкурент по модели.** Это **мультибренд-ритейлер со своим складом** (закупка →
перепродажа), премиум/стритвир, с 2008 (основатель Илья Гребенщиков). 2 офлайн-магазина в
Москве (Петровский б-р, Б. Полянка) + онлайн. 100+ брендов, **преимущественно иностранных**
(Stone Island, Stüssy, Woolrich, Nemen, Ten C, White Mountaineering, Baracuta, Macron) —
не каталог российских дизайнеров. WEARBASE = директория РФ-брендов с 0% комиссии и уводом на
бренд; brandshop = собственный ритейл иностранщины. Разная сторона предложения и аудитория →
**не источник РФ-лидов** и не модельный соперник.

**Чем он нам полезен — контент/SEO-бенчмарк (главное):**
1. **Редакционная «история бренда» на каждый бренд** — `/news/history/{brand}-istoria-brenda/`,
   title «{бренд} история бренда. Кто основал {бренд}». Это **ровно RAG-энциклопедия WEARBASE**,
   но у живого игрока с 2008 → доказывает, что контент-слой «история/кто основал» ранжируется и
   стоит усилий. Их библиотека историй — ориентир по структуре статьи и набору запросов
   («{бренд} история», «кто основал {бренд}»).
2. **Чистые односегментные слаги бренд-листингов** `/{brand-slug}/` (латиница, без мусора) +
   транзакционный гео-title «{бренд} — купить в интернет-магазине BRANDSHOP в Москве».
   Контраст с грязными слагами vitrine (`/brand/corpse+farm`) — модель канонизации брать с brandshop.
3. **Нишевый хаб `/sneakerhead/`** — «каталог самых редких моделей кроссовок»: отдельный
   контент-/трафик-магнит под узкий горячий интент (аналог стилевых хабов).
4. Лояльность/подарочные сертификаты (retention), чистый robots (закрыты `/login /register
   /search /*? /*route=`).

**Где он нам НЕ угроза:** иностранный ассортимент (не пересекается с РФ-лонгтейлом WEARBASE);
ru-only, без hreflang; собственный склад → нет стороны бренда и не релевантен оффер «0% комиссии».

**Пересечение в выдаче:** только по бренд-запросам марок, которые возят обе площадки (мало) +
по инфо-запросам «{бренд} история / кто основал» — там WEARBASE целит тем же RAG-контентом.

### Контент-модель `/news/history/` — референс для наших БЛОГ-статей (в подготовке)

> ⚠️ Это **блог-статья**, не описание карточки. Не путать жанры: карточное описание бренда у нас
> заточено под коммерч-интент (~250 слов, без подзаголовков) и менять его под эту формулу НЕ надо.
> Формула ниже — ориентир для **блог-раздела WEARBASE** (статьи-истории брендов, сейчас готовятся).


**Объём и каденс:** ~115–150 статей-историй (sitemap_news.xml). Контент-слой запущен ещё в
**2016** (первая дата в статьях), два больших залива — 2020-08/09 (слаги `{brand}-istoria-brenda`)
и 2022-01 (креативные слаги `{brand}-{тэглайн}`, напр. `stone-island-vremja-sobirat-kamni`),
дальше дозалив 2023–2025. **Блог жив**: на июнь-2026 публикуют ~еженедельно (C.P. Company, ASICS),
формат расширился с чистых историй до **гайдов по моделям** («гид по моделям ASICS Kinetic»).

**Анатомия статьи** (разобран Woolrich, ~650 слов, оригинальный редакторский текст):
- **Лид** — крючок-метафора + «Brandshop рассказывает историю …».
- **2–3 тематических подзаголовка** (не «История»/«Сегодня», а смысловые: «Американская мечта»,
  «Историю пишут одеяла»).
- **Плотные факты**: имя основателя, год, локация, сигнатурный продукт с годом, исторические вехи,
  «N поколений» — то, что отвечает на «кто основал {бренд}» и «история {бренд}».
- **CTA в конце** — «Приобрести можно на нашем сайте:» → ссылка на бренд-листинг (внутр. перелинковка).
- **meta-title формула**: «{Бренд} история <страны> бренда. Кто основал {Бренд}, коллекция …» —
  буквально под запросы `{бренд} история` / `кто основал {бренд}`.

**Что отсюда берём в блог-статьи:** структуру (лид → смысловые подзаголовки → факты с годами →
CTA на карточку бренда), длину ~600–700 слов, meta-title-формулу под «история/кто основал». ⚠️ **Сам их
список брендов нам не контент-источник** — это иностранные марки; WEARBASE целит тот же интент по
**российским** брендам, где у brandshop и конкурентов покрытия НЕТ → чистое окно.

Источники: brandshop.ru, /o-magazine/, /news/history/ (sitemap_news.xml ~115+ history-URL),
/sitemap.xml (catalog/products/news/other), robots.txt; история — Афиша Daily «магазину Brandshop 10 лет».
