# Ревью матрицы гардероба

Проверены сценарии родителя с детьми без личного входа, пользователя без семьи,
ручной классификации вещей, планирования покупок и загрузки фотографий.

## Исправленные проблемы

- Выбор колонок сбрасывался при смене сезона и после сохранения вещи. Теперь он
  хранится в браузере отдельно для каждого пользователя; новые участники видны
  по умолчанию. «Показать всех» возвращает все колонки.
- Исправленная вещь могла исчезнуть из текущего сезонного фильтра. Сохранение
  открывает подходящий сезон и прокручивает страницу к ячейке вещи. Ссылка на
  неклассифицированные вещи видна над таблицей.
- Поворот фотографии из галереи подменял большую обложку. Теперь обновляется
  только нужное фото, а обложка получает средний вариант изображения.
- Служебная команда поворота перезаписывала оригинал. Теперь и интерфейс, и
  команда сохраняют угол в базе. Исходные байты остаются прежними.
- Общие ссылки, кружки и подготовка образов читали исходные файлы без учёта
  нового угла. Теперь они используют производные изображения без EXIF.
  Поворот также меняет версию подготовленного изображения без фона.
- Распознавание ссылки на товар использовало отдельный свободный список
  категорий. Фото, ссылки и результаты фоновой обработки теперь используют
  справочник категорий; неизвестные значения не создают новые категории.
- Закрытые потребности игнорировали выбранный сезон. Теперь фильтр применяется
  к открытым и закрытым потребностям одинаково.

## Изображения

Новые загрузки очищаются от метаданных одним проходом GD в полном разрешении и
сохраняются в существующем приватном хранилище. EXIF-ориентация применяется к пикселям
до удаления метаданных; ручной поворот остаётся отдельным углом в базе.
Формат и прозрачность PNG/WebP сохраняются. Очистка применяется также к фото носки.
WebP создаётся при первом обращении: preview — до 320 px, medium — до 1280 px
по длинной стороне, без увеличения маленьких изображений. Учитываются EXIF и
ручной поворот; уменьшение выполняется перед поворотом для снижения расхода памяти.
Медиамаршруты возвращают только производные изображения; `size=original`, как и
неизвестные размеры, возвращает preview. Это защищает и старые файлы с метаданными.
Общие ссылки возвращают только веб-копии.

Производные файлы находятся в `var/uploads/wardrobe_variants`; это восстанавливаемый
кеш, его можно удалить без потери оригиналов. Старые файлы, уже перекодированные
до этой доработки, остаются исходниками для новых превью.

## Проверка

- PHPUnit: семейный доступ и изоляция личных потребностей, сезонные фильтры,
  классификация, категории vision, загрузка, сохранность исходных байтов,
  EXIF и ручной поворот, прозрачность PNG, ограничения размеров и авторизация медиа.
- Браузер, 1440 px и 393 px: собственная колонка, сохранение скрытых колонок,
  скрытие всех и восстановление, исправление вещи в другой сезон, добавление
  вещи ребёнку без его входа, поворот фото галереи, отсутствие внутренней прокрутки.
- PHP/Twig и контейнер Symfony: проверка синтаксиса и зависимостей.

Новых очередей, библиотек изображений и отдельных хранилищ метаданных не добавлено.
