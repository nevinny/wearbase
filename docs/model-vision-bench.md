# Бенч vision-моделей (распознавание одежды по фото)

Сравнение локальных ollama-моделей на распознавании одежды по фото:
`app:bench:vision <model> [--limit=30] [--doc=] [--manifest=path.jsonl]`.

Два источника набора:
- **каталог** (по умолчанию): N товаров (активные, с категорией, с фото на диске и с
  известным цветом хотя бы одного варианта), детерминированный набор (`ORDER BY
  product.id`, одни и те же товары для всех моделей). Эталон — `product_category.title`
  (категория) и цвет первого варианта с непустым `color` (`product_variant.color`).
- **`--manifest`**: готовый JSONL (строки `{"id","path","category","color","ai_prefilled"}`)
  — эталон на реальных вещах гардероба (финальные `category`/`colorName` вещи, а не
  подсказка модели). Личные фото и manifest собираются отдельно и живут только на Mac
  вне git. `ai_prefilled` (вещь была принята из AI-черновика с подсказкой) разбивает
  сводку на когорты true/false/null — так виден возможный уклон эталона к модели,
  которая делала подсказку.

Промпт и парсинг ответа в обоих режимах — те же, что в проде
(`WardrobeAiService::suggestFromPhoto`/`analyzePhoto`), вызов идёт через
`analyzePhotoWithLocalModel()` — без кеша/согласия/лимита/usage-лога.

Метрика двухуровневая:
- **точное** совпадение (`matches()`): регистр/ё/небуквенные символы игнорируются,
  засчитывается точное совпадение, вхождение подстроки или общий 4-символьный префикс.
- **групповое** (мягче — для manifest-эталона со свободными формулировками вроде
  «серо-голубой (мокрый асфальт)» или «розовый; салатовый; белый»): категория сводится
  к одной из ~6 групп (верх/низ/платья/верхняя одежда/обувь/аксессуары) по ключевым
  словам, цвет — к одному из ~12 семейств (чёрный/белый/серый/бежевый-коричневый/
  красный-бордовый/розовый/оранжевый/жёлтый/зелёный-оливковый/голубой-синий/
  фиолетовый/металлик); эталон с несколькими цветами через ";" засчитывается, если
  семейства пересекаются хотя бы по одному значению.

Метрики: доля валидных JSON-ответов, точное и групповое совпадение категории/цвета,
среднее время запроса (сек). Поштучный лог каждого прогона (эталон рядом с ответом
модели, для ручной проверки) — `var/bench/vision-<model>.jsonl`.

| модель | N | valid json | категория точно | категория группа | цвет точно | цвет семейство | среднее, с |
|---|---|---|---|---|---|---|---|
