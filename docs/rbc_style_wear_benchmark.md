## Что перенять (дельта относительно разбора Т—Ж)

Нового для заимствования почти нет — карточка Т—Ж строго сильнее (фикс-поля, якоря, AggregateRating). Из РБК Стиль:

1. **Цитата дизайнера в карточке** («что объединяет…») — живой E-E-A-T-элемент, которого нет у Т—Ж; в наши листиклы/карточки бренда можно подмешивать реальную цитату основателя из RAG-корпуса (только реальную, не генерить).
2. **Блок «материалы и производство»** как отдельная секция — совпадает с нашим RAG-подходом «данные из фактов», подтверждение паттерна.
3. Антипример: непереиздаваемая страница 2019 г. с hex-URL и без ItemList — подтверждает нашу ставку на вечнозелёные человекочитаемые URL с ежегодным обновлением (вывод Т—Ж-разбора).

Механика импорта — временная команда `app:tmp:import-rbc-style-leads` по образцу `app:brand:import-leads` (+ BrandLink website + city; повторная проверка по домену И имени перед вставкой), dry-run → боевой → файл удалён, в git не попадал. Сырой HTML — во временном scratchpad сессии (не в репо).
