## Ключевые инсайты

1. **~100% нашего поискового спроса — навигационный (по имени бренда). Discovery-трафика нет.**
   68% запросов точно матчатся на бренд; остаток («cortisoljeans», «йолло», «загон бренд», «ivolga одежда»,
   «sergei desev») — те же бренды в другом написании. Категорийных запросов («российские бренды одежды»,
   «streetwear», «аналоги zara») в топе нет. Люди ищут конкретную марку, которую уже знают.

2. **CTR ~0.8% на обоих движках — потому что мы на позиции 9–13, ниже сайта бренда и маркетплейсов.**
   Суммарно ~50 кликов/неделю на оба поиска. Мы видимы, но структурно не выигрываем навигационный клик:
   на запрос «yollo» пользователю нужен yollo.ru, а мы — агрегатор на ~9-м месте.

3. **Яндекс — наш реальный канал; Google почти не индексирует.**
   478 брендов в поиске Яндекса против 81 с показами в Google; **400 брендов — только в Яндексе**.
   Google-индексация — бутылочное горлышко (плюс заморозка покрытия с 12.06).

4. **Крошечный след относительно каталога:** ~478/7164 в Яндексе, ~81 в Google. Бо́льшая часть каталога
   поиску невидима. Рычаг роста — потолок индексации/дрип, а не «ещё контента».

5. **Блог/GEO-контент пока даёт ноль поисковой тяги:** 0 показов блог-URL в Google за 28 дней. Статьи новые +
   Google заморожен → рано; тезис «нас начнут цитировать/ранжировать по discovery» пока не подтверждён.
   Первые сигналы смотреть по Яндексу.

6. **Монетизация через клик-трекинг подтверждается болью, а не объёмом.** ~50 исходящих кликов/нед — дашборд
   `/admin/clicks` будет показывать почти нули, пока позиции/индексация не вырастут.

## Что делать (по приоритету)

1. **Выигрывать навигационный SERP как «лучший сторонний результат».** Раз ищут по имени бренда — обгонять
   маркетплейсы по «{бренд} отзывы / где купить / аналоги»: добавить на карточку эти модули. С ~9 до 3–5 —
   самый быстрый анлок кликов. Цели — из списка быстрых побед выше.
2. **Конвертировать навигационный трафик в discovery** перелинковкой «пришёл на бренд X → похожие бренды».
3. **Google-индексацию** (400 Яндекс-only) чинить, но она гейтится заморозкой Google + потолком дрипа —
   низкий near-term ROI; держим IndexNow + дрип, ждём разморозки.
4. **Discovery/GEO (листиклы/хаб)** вести как отдельную greenfield-ставку и мерить по Яндексу; не смешивать
   с навигационной реальностью и не считать успехом заранее.

## Оговорки метода

- Яндекс: анализ по топ-500 запросам (из 893); хвост даёт ~0 кликов, вывод не меняет.
- Google: покрытие индекса заморожено Google с 12.06 → «в индексе 21» — устаревший снимок; живой сигнал по
  Google — показы Search Analytics (81 бренд), не coverage.
- Классификатор «навигационный/общий» — по совпадению с title/slug; недооценивает навигационные (варианты
  написания), т.е. доля навигационных на деле ещё выше.
- Данные publish_at на Mac-БД неинформативны (проставляются на проде) — след меряем по показам/индексу, не по статусу.
