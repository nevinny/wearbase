# Влияние AI-сдвига Google на WEARBASE

> Источник анализа: разбор видео Rush Agency «GOOGLE УБИЛ SEO? Самое крупное обновление поиска за 25 лет»
> (Google I/O, 19 мая; AI Mode > 1 млрд MAU; May Core Update с 21 мая) — наложенный на фактическую
> инвентаризацию контент/SEO-поверхностей проекта (чтение репозитория, июнь 2026).
> Связано: [global_analogs.md](global_analogs.md) (click-трекинг = приоритет №1), [marketing_seo.md](marketing_seo.md)
> (индексация), [rag_pipeline.md](rag_pipeline.md) (grounded-генерация), [competitors.md](competitors.md).

## Вердикт

**moderate-risk с уже наполовину построенным моатом.** Там, где контент grounded (RAG-карточки брендов =
first-party факты, которых нет в одной выдаче), WEARBASE защищён — AI Overview такое не заменяет одной фразой.
Недозащищён по двум фронтам: **не был построен click-трекинг** (заявленный приоритет №1 — теперь реализован,
см. ниже) и **не вычищен generic-слой** (boilerplate-FAQ + тонкие заглушки + фейк-рейтинги листиклов), который
выглядит ровно как «зона риска» из видео.

Главное расхождение с видео: для одёжного каталога это **не экзистенциальная угроза**. Видео переоценивает риск
для визуально-транзакционной ниши и недооценивает устойчивость бренд-навигации (см. «Нюанс»).

## Что уже сделано правильно (это и есть моат)

- **Ядро каталога grounded-original, а не pretrain-вода.** ~97% (3320/3425) опубликованных брендов `grounded=1`;
  проверяемая конкретика, которой нет в priors модели («подошва АНТИГОЛОЛЁД и кожа АКВАСТОП», «с 2005, 280 моделей,
  Пермь», размеры 44–54). Это «оригинальность данных», которую награждает Core Update.
- **Архитектурный запрет на галлюцинации** — `LlmService.php:119-130` (только факты из RAG-блока), `:135-139`
  (детерминированный маркер `НЕДОСТАТОЧНО_ФАКТОВ` вместо воды). Многослойный gate (cosine≥0.5, chunks≥3,
  fashion-сигналы, near-dup Jaccard, article-QA) не публикует ~2850 брендов; прод-демон `--grounded-only`.
- **Системный E-E-A-T** (Author → Person → страница Анны Семянниковой, байлайн, LLM-судья на фабрикацию в блоге).
- **Чистая индексация** — ru index / не-ru `noindex,follow` + canonical→/ru, sitemap только ru, 410/404/200-tombstone
  по статусу; приоритет sitemap привязан к длине описания.
- **Богатый валидный `schema.org @graph`** (Organization+LocalBusiness+FAQPage+BreadcrumbList на бренде,
  Product+AggregateOffer на товаре, Person на авторе) + `/llms.txt`.
- **Реальный destination-слой**: физ-магазины (LocalBusiness), верифицированные контакты, краудсорс-валидация
  (`dp-vote` + `data-nosnippet`), плотный внутренний линк-граф (`findRelatedHard` + добор до 6).

## Quick wins (дёшево)

1. Убрать FAQPage из JSON-LD там, где нет реального `brand_faq` (`show.html.twig:132-169`) — рендерить схему только при `faq_status=done`.
2. Вычистить тест-мусор в `brand_faq` одним SQL-проходом.
3. Деиндексировать тонкие/`grounded=0` карточки (`noindex,follow` + убрать из sitemap; `base.html.twig` + `SitemapController.php:166-181`).
4. Чинить `Org.url/sameAs` — `own_site` детерминированно; добавить Instagram в `sameAs`.
5. Обрезать `anons` по границе слова (`GenerateBrandContentCommand.php:471`).
6. В GSC сегментировать по типу страницы; смотреть позиция-vs-CTR (Core Update vs AI Mode).

## Стратегические ставки

1. **Click-трекинг исходящих переходов** — ✅ **реализовано** (см. ниже).
2. **Собственные первичные данные** (верифицированные цены/наличие, размерные сетки, популярность из click-трекинга,
   deep-link на товар) → витрина становится незаменяемым выдачей destination.
3. **Дрип-по-ценности, не по дате** — приоритетно индексировать grounded-богатые карточки.
4. **Переформатировать листиклы** из фейк-рейтингов в честные гиды + распространить anti-fabrication судью на внешние площадки.
5. **Строить бренд-спрос** (маркетинг-роадмап, упоминания, интервью основателей) — самый устойчивый к AI-сдвигу сигнал.

## Нюанс — где видео не право про нишу

- **Переоценивает риск для одежды.** Визуально-транзакционный интент («как выглядит коллекция», «подойдёт ли посадка»,
  «где купить») текстовый AI-ответ закрывает плохо. Zero-click бьёт по «что за бренд X», но не по покупательскому пути.
- **Недооценивает бренд-навигацию.** Запросы по имени бренда навигационны; WEARBASE как entity-досье с физ-магазинами
  цитируется как источник, и клик к нему сохраняется лучше.
- **Ось «обесценивание массового AI-контента» — попутный ветер, не угроза.** Grounded-RAG архитектурно противоположен
  «AI пересказывает AI». Видео бьёт по конкурентам (vitrine.market без RAG; local-brands.ru — статичный список).
- **Где видео право без скидок:** листиклы «ТОП-N рейтинг 2026» с подложным №1 и фейк-персонами.
- **Чего видео не учитывает про агрегатора:** главный риск не в замене контента ответом, а в том, что клик к бренду
  уходит **неизмеренным** — проблема монетизационной модели, острее самого zero-click.

## Реализовано: трекинг исходящих кликов (`/go/{id}`)

Закрывает риск №1. Редирект-прокладка измеряет переходы посетителей на ссылки бренда (сайт/соцсети/маркетплейсы).

**Поток:** ссылки в шаблонах указывают на `/go/{brandLinkId}` → `OutboundClickController::go()` находит цель **из БД**
(open-redirect невозможен) → пишет клик + инкрементит счётчик → `302` на реальный URL.

| Компонент | Файл |
|---|---|
| Контроллер-редиректор `/go/{id}` | `src/Controller/OutboundClickController.php` |
| Сущность лога (append-only) | `src/Entity/BrandOutboundClick.php` |
| Репозиторий (`topBrands`, `countForBrand`) | `src/Repository/BrandOutboundClickRepository.php` |
| Счётчик популярности | `Brand::$outboundClickCount` |
| Миграция (`brand_outbound_click` + столбец) | `migrations/Version20260627_brand_outbound_click.php` |
| Rate-limiter `outbound_click` | `config/packages/rate_limiter.yaml` |
| PUBLIC_ACCESS `^/go/` | `config/packages/security.yaml` |
| `Disallow: /go/` | `public_html/robots.txt` |
| Прокладка в шаблонах | `tailwind/brand/links.html.twig`, `tailwind/brand/show.html.twig` (CTA), `catalog/show.html.twig` (товар) |

**Свойства** (по образцу outreach-трекинга `OutreachController`):
- Stateless, без CSRF; горячий путь — нативный SQL.
- **Open-redirect невозможен**: цель берётся из `brand_link.link_url` по id, не из query.
- Редиректит только при `brand.status='active'`; иначе → главная.
- Боты (UA-регексп) **редиректятся, но не учитываются** — статистика не искажается сканерами.
- `X-Robots-Tag: noindex` + `Referrer-Policy: no-referrer` на ответе; `ua_hash = sha256(UA)` (без PII).
- Денормализованные `link_type` (website/instagram/.../marketplace) и `target_host` — группировка в отчётах без JOIN.

**Что даёт:** доказуемый реферальный трафик бренду (питч/удержание подписки), сигнал популярности
(`brand.outbound_click_count` → сортировка), и опцион на transaction/affiliate-монетизацию (модель Lyst/Musinsa).

**Дальше (не входит в этот шаг):** дашборд кликов в ЛК бренда; отчёт «топ-брендов по кликам» в админке
(`BrandOutboundClickRepository::topBrands`); deep-link на товар маркетплейса вместо домена.
