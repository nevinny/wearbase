# Foreground retry загрузки гардероба

Фото, выбранные при явном согласии на приватную обработку, временно сохраняются в IndexedDB
текущего браузера. Очередь содержит только pending Blob, имя/MIME, ID профиля, случайный
idempotency key, статус и флаг consent. Email, имя профиля, распознанные атрибуты и ответы сервера
не сохраняются.

Повтор запускается только в foreground: при открытии страницы и событии `online`. Background Sync
не используется и не обещается. Service Worker не перехватывает POST и не кладёт фото или private
responses в Cache Storage.

- успешная загрузка удаляет Blob из IndexedDB;
- сетевой сбой оставляет запись pending;
- `401`/редирект на login останавливает очередь и просит войти, не удаляя Blob;
- пользователь может отменить каждый файл отдельно;
- явный logout сначала полностью очищает очередь;
- серверный content hash остаётся окончательной exactly-once защитой при неясном исходе запроса.

Очереди разных членов семьи разделены по `member`; страница отправляет только записи выбранного
профиля. Данные остаются локально до успешной отправки, отмены или logout.
