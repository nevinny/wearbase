# WEARBASE Wardrobe MVP

Статус: в разработке с 2026-07-23.

## Архитектурное решение

Новый MVP развивается совместимо с уже работающим личным, семейным и AI-гардеробом.
Существующие маршруты `/account/wardrobe`, Telegram-ввод, передачи вещей и локальное
vision-распознавание сохраняются.

Первый фундаментальный срез:

- `Wardrobe` — контейнер вещей пользователя; default-гардероб создаётся лениво;
- `WardrobeCategory` — расширяемый справочник категорий;
- `WardrobeItem.wardrobe` — новая связь с контейнером;
- `WardrobeItem.categoryRef` — новая связь со справочником;
- старые `user`, `category` и `photo` временно сохраняются для обратной совместимости.

Миграция `Version20260723_phase_wardrobe_mvp` создаёт таблицы, добавляет nullable-связи
и привязывает существующие вещи к default-гардеробам. Следующие срезы добавят галерею,
полную карточку, статусы заполнения, архив, фильтры, статистику и экспорт.

## Инварианты

- цены хранятся только в RUB;
- пользовательские удаления остаются soft-delete;
- текущий владелец вещи (`WardrobeItem.user`) продолжает меняться при семейной передаче;
- `originalOwner` и журнал `WardrobeTransfer` сохраняют историю;
- AI и Telegram создают вещи через тот же default-гардероб;
- dev использует MySQL, SQLite — только тестовый контур.
