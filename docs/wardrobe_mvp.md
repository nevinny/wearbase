# WEARBASE Wardrobe MVP

Статус: в разработке с 2026-07-23.

## Архитектурное решение

Новый MVP развивается совместимо с уже работающим личным, семейным и AI-гардеробом.
Существующие маршруты `/account/wardrobe`, Telegram-ввод, передачи вещей и локальное
vision-распознавание сохраняются.

Первый фундаментальный срез:

- `Wardrobe` — контейнер вещей пользователя; default-гардероб создаётся лениво;
- `WardrobeCategory` — расширяемый справочник категорий;
- `WardrobeItem.wardrobe` — новая связь с контейнером;
- `WardrobeItem.categoryRef` — новая связь со справочником;
- старые `user`, `category` и `photo` временно сохраняются для обратной совместимости.

Миграция `Version20260723_phase_wardrobe_mvp` создаёт таблицы, добавляет nullable-связи
и привязывает существующие вещи к default-гардеробам.

Второй срез (`Version20260724_phase_wardrobe_details`):

- быстрое добавление сохраняет минимальную карточку как черновик;
- полная форма редактирования использует справочник категорий и подкатегорий;
- добавлены бренд, цвет, материал, сезон, страна, уход и статус вещи;
- `WardrobeManager` вычисляет `draft`, `basic` или `complete` после сохранения;
- доступна кнопка «Сохранить и добавить следующую».
- фото, найденное по ссылке Wildberries, проходит allowlist/MIME/size-проверку и
  сохраняется локально как обложка карточки; доступен пакетный backfill.

Третий срез (`Version20260726_wardrobe_gallery_archive`):

- у вещи появилась галерея из нескольких JPG, PNG или WebP (до 8 файлов за запрос,
  до 10 МБ каждый);
- пользователь выбирает обложку, а старое поле `WardrobeItem.photo` синхронизируется
  с ней для совместимости с AI, Telegram и существующими карточками;
- удаление фотографии и вещи не уничтожает пользовательские данные: фотографии
  получают `deleted_at`, вещи перемещаются в восстанавливаемый архив;
- прежние фотографии автоматически добавляются в галерею миграцией без перемещения
  файлов.

Четвёртый срез:

- поиск по названию, бренду, категории, цвету, размеру и сквозному номеру `#0001`;
- фильтры по категории, бренду, цвету, размеру, сезону и статусу заполнения;
- поиск работает как в активном гардеробе, так и в архиве;
- значения фильтров и результаты строго ограничены выбранным членом семьи;
- параметры сохраняются при переключении «Вещи / Архив» и возврате из карточки.

Пятый срез:

- отдельный экран статистики для каждого участника семейного гардероба;
- активные и архивные вещи, общая стоимость, средняя цена и доля любимых вещей;
- заполненность карточек и распределения по категориям, сезонам, брендам и цветам;
- распределения по состоянию вещи и семейному статусу носки;
- сравнительные карточки участников семьи;
- показатели ведут в соответствующий отфильтрованный список вещей.
- в фактах вещи можно выбрать несколько из 20 стилей; интерфейс показывает их
  отдельными метками без эмодзи, а база хранит массив стабильных кодов.

Следующий срез добавит JSON/CSV-экспорт.

## Инварианты

- цены хранятся только в RUB;
- пользовательские удаления остаются soft-delete;
- текущий владелец вещи (`WardrobeItem.user`) продолжает меняться при семейной передаче;
- `originalOwner` и журнал `WardrobeTransfer` сохраняют историю;
- AI и Telegram создают вещи через тот же default-гардероб;
- dev использует MySQL, SQLite — только тестовый контур.
